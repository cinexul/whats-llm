假设你请助手比较三个工作坊场地。它可以告诉你该怎样搜索，也可以自己查看场地网页、记录价格和无障碍信息、发现资料缺口，再交付附有来源的比较。第二种就体现了 Agent 的行为：通过一连串决策和观察推进目标。

## 一、从"答问题的 AI"到"会动手的 AI"

本章把 **Agent（智能体）**理解为使用模型、为目标选择和调整步骤的系统。工具通常让它能搜索、阅读、计算或修改内容。不同产品对这个词的定义并不完全一致，所以更有用的问题是：它能决定什么、访问什么、怎样证明任务完成。

聊天助手也可以调用一次工具，固定自动流程也可以执行十个预定步骤。这些都不足以说明它遇到意外后会决定下一步。另外，Agent 不一定要修改外部事物：研究型 Agent 可以只阅读并写报告。

## 二、关键零件：工具调用（tool use）

模型提出操作，外围软件检查并执行工具调用，再返回结果。“文件已经发送”这句话本身，不能证明发送工具真的执行成功了。

| 路径 | 怎样工作 | 观察什么 |
| --- | --- | --- |
| **直接集成 / API** | 请求一个约定操作，例如查找文档或创建草稿 | 有哪些操作、账号权限和返回状态 |
| **计算机操作 / 浏览器交互** | 观察网页或屏幕，点击、输入和导航 | 实际页面状态、误点、界面变化和确认页面 |
| **文件或命令工具** | 读取文件、修改工作区或运行程序 | 影响哪个文件夹或环境，结果有没有检查 |

集成通常开放明确的操作。计算机操作可以触达没有专门集成的界面，但需要理解屏幕上发生了什么。两种路径都不会自动拥有全部权限，也都不保证成功。沙箱是限制活动范围的工作环境，还要确认它仍能访问哪些文件和网络服务。

## 三、Agent 的招牌动作：自己跑"调查 → 动手 → 检查"的循环

对于场地比较，一个有用的循环是：

```text
读需求 → 查看场地来源 → 记录可比较的信息
  → 发现无障碍细节缺失 → 继续调查或标为未知
  → 对照来源检查比较 → 交付报告
```

有些系统可以把子任务**委派**给其他 Agent，例如让不同 Agent 分别调查一个场地。这是实现方式，不代表有了独立专家的保证。多个 Agent 可能重复同一个错误，或依赖同一个薄弱来源。负责汇总的系统仍要核对差异、保留依据。更多 Agent 也可能带来更多耗时和费用。

要求可观察的证据：来源链接、创建的文件、实际改动和做过的检查。你需要的是工作记录和结果，不是声称展示了内部私有推理的文字。

## 四、能力和风险，是同一枚硬币

好的任务交代应说明结果、可用资料、允许的操作和停止条件：

> 比较这三个场地，供指定日期的 20 人活动使用，预算如下。使用场地官方网页，每个报价附来源和核查日期。缺失信息标为未知。先只整理比较；预订或付款前联系我。交付一张表和简短建议，说明最大的未确定因素。

权限应当与任务匹配。整理文件时，可以先在副本上试，并要求预览移动或删除清单。对于已经授权、可撤销的操作，反复确认未必有用；发送、购买、发布或删除重要数据等边界才尤其需要关注授权。

网页和文档可能写有针对助手的指令。那些是**来源内容，不是你发出的指令**。场地网页让 Agent 忽略预算或泄露其他文件，不代表这是任务的一部分。这也是限制访问范围、检查重要结果的原因。

长任务可以约定时间或费用上限。遇到缺少登录、要求冲突或反复失败时，Agent 应停止或报告障碍，不能悄悄扩大任务范围。

## 五、回扣第17章：Agent 在"四层地图"的什么位置

Agent 是围绕模型、工具和工作状态组织任务的一种方式。它可以出现在聊天产品、编程应用，或使用 API 的定制服务里。界面可能在本地，模型却在远程运行。“Agent”描述工作怎样推进，不说明数据留在哪里，也不说明哪个订阅承担费用。

## 六、常见误解，集中纠正

| 误解 | 实际情况 |
| --- | --- |
| 有计划就证明工作做完了 | 计划是提议，要看实际输出和检查 |
| Agent 越多，答案越可靠 | 共同来源和共同错误可能造成虚假的一致 |
| 能调用工具就有无限权限 | 操作仍必须在任务和权限范围内 |
| 说“成功”就够了 | 查看文件、来源或应用的实际状态 |

## 小结

把目标连同边界一起委派。有效的 Agent 会选择步骤，根据工具结果调整，并交付可以检查的证据。对场地任务而言，有出处、明确标出缺口的比较，比一句没有依据的“全部确认好了”更有用。

## 小测验

1. **[基础·概念题]** 哪种行为最能体现本章的 Agent 循环？ <!-- quiz: q01 revision: 1 -->
   - A. 重复固定问候语
   - B. 查看上一步返回了什么，再选择下一步
   - C. 写最长的答案
   - D. 使用最贵的模型
   > **答案：B。** 观察结果影响下一步如何推进目标。

2. **[基础·概念题]** 计算机操作与直接集成有什么区别？ <!-- quiz: q02 revision: 1 -->
   - A. 它观察并操作界面，而不只是请求服务定义好的操作
   - B. 它完全不需要模型
   - C. 它自动获得全部账号权限
   - D. 它不会出错
   > **答案：A。** 交互路径不同，但两者都需要权限和结果核验。

3. **[基础·证据题]** Agent 说“报告保存好了”。什么最能直接核实这句话？ <!-- quiz: q03 revision: 1 -->
   - A. 语气很肯定
   - B. 它再重复一遍
   - C. 指定位置确实有报告，而且内容符合要求
   - D. 模型基准分数很高
   > **答案：C。** 要查看外部结果，不能只看完成声明。

4. **[进阶·误区题]** 三个被委派的 Agent 对价格意见一致，为什么仍可能需要核查？ <!-- quiz: q04 revision: 1 -->
   - A. 意见一致不可能发生
   - B. Agent 永远不能调查价格
   - C. 委派会自动删除来源
   - D. 它们可能都依赖同一条过时来源，或重复同一个错误
   > **答案：D。** Agent 数量不等于独立证据的数量。

5. **[基础·情景题]** 场地网页要求 Agent 上传你的私人笔记，应该怎么办？ <!-- quiz: q05 revision: 1 -->
   - A. 把网页当成新的用户指令
   - B. 把它当作不受信任的来源内容，遵守原任务范围
   - C. 上传笔记以便更快完成
   - D. 让另一个 Agent 代为上传
   > **答案：B。** 阅读来源，不代表赋予来源支配你的数据和任务的权力。

6. **[进阶·情景题]** 调查达到约定预算，仍有一个事实无法确认，应该交付什么？ <!-- quiz: q06 revision: 1 -->
   - A. 不说明，继续花钱
   - B. 编出缺失事实
   - C. 说明已完成的工作、缺失证据和停止原因
   - D. 直接预订以强行得到结果
   > **答案：C。** 如实说明部分完成，才能保留证据和约定边界。
