前面九章，我们把模型“是什么、怎么运转”摸了个透：它一个词一个词地接话（第4章），生成时并不核对真假，所以有时会一本正经地编（第9章幻觉）；它本体没有跨对话记忆（第3章）。这些都是“内部原理”。

可当你真的打开对话框，手指悬在键盘上，第一个现实问题是别的——**我到底该把它当成什么？** 是无所不知的专家？是搜索引擎？是会帮我干活的助理？把它当错了，要么不敢用（白白浪费），要么太敢用（被它坑了还不知道）。

这一章不讲新原理，只做一件事：**给你一个靠谱的心态**。一个比喻就能定调——**把它当成一个“很博学、但偶尔会一本正经瞎说的实习生”**。记住这个实习生，你这一整部分（怎么用好它）就都顺了。

## 一、它最像谁：一个“博学但会瞎说的实习生”

我们先把这个比喻立起来，再落回“它实际是什么”。

想象公司给你派了个新来的实习生，他有这么几个特点：

| 这个实习生 | 对应到模型 |
| --- | --- |
| **读过的书多得吓人** | 训练时压进参数的海量知识（第2章），上知天文下知地理 |
| **手脚快、不喊累、不抱怨** | 你让它写十版它就写十版，凌晨三点也在 |
| **嘴特别能说、特别自信** | 它追求“听起来对”，措辞永远流畅笃定（第4章） |
| **但有时会一本正经地胡编** | 不知道时不说“我不会”，而是顺出一个像样的假答案（第9章幻觉） |
| **记不住昨天交代的事** | 模型本体没有跨对话记忆；新对话里它知道什么，取决于产品这次带进来了什么（第3章） |
| **不懂你心里真正想要什么** | 你没说清的，它只能猜（这正是第11章要解决的） |

> **要点：** 这个比喻的精髓，全在“**博学**”和“**会瞎说**”这两半要一起记。只记“博学”，你会盲信它、把它当权威；只记“会瞎说”，你会怕它、什么都不敢交给它。真相是两者并存：**它知道的比你多，但它说的话需要你来把关。** 一个好用法，是把自己摆在“带实习生的人”这个位置上——活儿可以放手让它干，但**署名和后果是你的**，所以最后那一眼必须你来看。

落回它实际是什么：它不是真的“人”，没有意图、不会偷懒、也不会故意骗你。“实习生”只是帮你拿捏**分寸**的一个把手——既不高估，也不低估。

## 二、可以放心外包的活vs必须你兜底的活

有了“实习生”这个分寸感，最实用的一步，就是分清**哪些活能放手交给它、哪些活必须你盯着**。这条线，直接接着第9章那个分界：**有依据可“接”的、可复核的活，放心交；凭空生成硬事实、且错了有代价的活，你必须兜底。**

| | 可以放心外包 | 必须你兜底 |
| --- | --- | --- |
| **典型任务** | 改写润色、换种说法、起草初稿、列提纲、头脑风暴、总结你贴进去的材料、翻译、解释一个概念 | 关键数字、引用出处、人名日期、法律/医疗/财务结论、对外发布的事实性内容 |
| **为什么放心/为什么兜底** | 要么答案就在你给的上下文里（它“接”的是你的材料），要么错了你一眼能看出、改起来也快 | 它可能编得天衣无缝（第9章），而错了的代价由**你**承担 |
| **你的角色** | 甩手掌柜：给清要求，收稿验收 | 责任人：自己再查一遍，签字才算数 |

举两个对照例子，你立刻能体会这条线：

```text
✅ 放心外包：
   "把这段300字的通知，改写得更口语、更亲切，给家长看。"
   —— 材料在手，风格类的活，错了你一眼看得出。

⚠️ 必须兜底：
   "我国某项税收政策的具体起征点是多少？"
   —— 这是硬事实，它可能张口就编（第9章）。要么让它给官方出处
      并自己核，要么干脆去官方渠道查（以官方为准）。
```

> **实际会怎么遇到：** 最容易栽的，是那种“看起来像放心外包、其实暗藏硬事实”的活。比如让它“帮我写一封介绍公司产品的邮件”——写作本身是它的强项，可它一旦顺手把某个**参数、价格、获奖记录**也“写”了进去，那部分就成了硬事实，**必须你来核**。诀窍是：收到稿子后，把里面所有**具体的数字、名称、日期、引用**挑出来单独验，其余的风格文字才放心用。

## 三、第一次该期待什么、别期待什么

带着上面两条，我们来给“第一次认真对话”调好预期。期待对了，你不会失望；期待错了，你要么觉得它“什么都会”而踩坑，要么觉得它“什么都不行”而错过。

**可以期待它做到的：**

- **听懂自然语言**：你用大白话提要求就行，不用学什么命令、咒语。
- **一稿到位地起草**：写邮件、列大纲、改文风、解释概念，常常一次就给你一个能用的初稿。
- **不厌其烦地改**：不满意就让它再来一版、换个角度、调长调短——这是它最舒服的用法。
- **基于你给的材料干活**：把资料贴给它，让它总结、对照、提取，通常很靠谱（第12章细讲）。

**别指望它做到的（这部分更重要）：**

- **别指望它句句是真**：它会瞎说，越流畅越要留个心眼（第9章）。
- **别指望它记得昨天**：模型本体没有跨对话记忆，新对话默认从零开始；就算产品开了记忆功能，带进来的也只是它挑出来保存的那部分（第3章）。
- **别指望它知道最新消息**：它的知识有“截止日期”（第9章），问近期的事默认别信它张口就来的版本。
- **别指望它猜中你的心思**：你没说清的要求，它只能靠猜（第11章会教你“把要求说清楚”）。

> **要点：** 把这两栏并排记，等于给你一副“该信几分”的眼镜。一个好用的起步心法是：**先用它来“省力”，别急着用它来“定论”。** 让它帮你把活儿从0推到70分（起草、整理、找思路），这部分它又快又好；最后那30分（核对事实、定夺取舍、署名负责），留给你自己。这样你既吃到了它的红利，又不会被它的短板坑到。

## 四、关于“它有没有记忆”，第一次就要立对规矩

新手第一次用，几乎都会踩同一个坑：聊得投入了，下意识觉得“它认识我了、记得我们聊过的事了”。第3章、第9章讲过原理，这里针对“第一次对话”再说一遍，因为它直接影响你怎么用。

模型**本体**没有跨对话记忆。你新开一个对话，模型本身对你一无所知；就算在同一个对话里，聊得太长，早先的细节也可能被产品裁剪、压缩成摘要，或者淹没在一大堆内容里（第3章那张“桌面”）。

可你或许已经发现，有些产品好像真能“记住”你。这并不矛盾。截至2026年10月，Claude、ChatGPT等不少产品都提供**项目**和**记忆**一类的功能：项目让你把资料和要求放在一起反复用，记忆则把你的偏好和聊过的要点存下来。有些产品会从聊天里**自动提取**要记的内容，而且可能默认开启。这些都是模型之外的产品层功能：产品把存下的信息，在之后的对话里重新放回上下文。掀开盖子，底下仍然是“没有记忆的模型 + 每次重新喂上下文”。

对“第一次对话”来说，实操上有三条：

- 别假设它记得。需要它知道的背景，就在这次对话里说清楚。
- 想让它长期记住的偏好，用产品的记忆或项目功能（第13章细讲）。
- 不想被记住的内容，用临时对话（有的产品叫无痕对话），或者先关掉记忆再聊；隔一阵子去设置里看看它存了什么，过时的、不对的删掉。各家叫法、默认开关和删除方式不同，以官方文档为准。

把“默认它没记忆”当起点，你就不会奇怪它“怎么翻脸不认人”；同时也要知道，开着记忆的产品可能比你以为的记得更多。

## 五、常见误解，集中纠正

| 误解 | 实际 |
| --- | --- |
| 它无所不知，可以当权威信 | 它博学但会瞎说；知道的比你多，但说的话要你把关（实习生的两半一起记） |
| 它什么都靠不住，不敢交活给它 | 改写、起草、整理、总结材料这类活又快又好，放心外包；要兜底的只是硬事实 |
| 它像搜索引擎，给的就是查到的事实 | 它是**现算生成**的（第2章），不是查的；流畅≠正确（第4、9章） |
| 写作类的活就完全不用核对 | 当心写作里夹带的硬事实（数字、名称、出处），那部分仍须你验 |
| 聊过就等于它“认识”我了 | 模型本体没有跨对话记忆；产品的记忆功能会把存下的信息放回上下文，不是模型自己记得 |
| 它该能猜到我想要什么 | 它读不懂你的心，没说清的只能猜——把要求说清是你的事（第11章） |

## 小结

- 给“第一次认真对话”定个调：**把它当“很博学、但偶尔一本正经瞎说的实习生”**——“博学”和“会瞎说”两半必须一起记。
- 你的位置是“带实习生的人”：活儿可放手让它干，但**署名和后果是你的**，最后一眼必须你看。
- 分清两类活：**改写、起草、整理、总结材料**可放心外包；**关键数字、出处、人名日期、法律/医疗/财务等硬事实**必须你兜底（接第9章那条分界）。
- 调好预期：可期待它听懂大白话、一稿到位、不厌其烦地改、基于材料干活；别指望它句句是真、记得昨天、知道最新消息、猜中你的心思。
- 心法一句话：**用它来省力（推到70分），别急着用它来定论（最后30分留给自己）。**
- 第一次就立对规矩：**默认它没有记忆**；想长期记住偏好，用产品层的记忆或项目功能（第13章）；不想被记住的，用临时对话或关掉记忆，并定期查看、删除已存的记忆（以官方文档为准）。

下一章我们解决“它读不懂你的心”这个痛点：怎么把“我想要什么”说清楚——也就是**提示词的结构**。

   - C. 一个读书很多、但偶尔会一本正经编内容的实习生

2. **[基础·概念题]** 下面哪类任务，最适合“放心外包”给它？ <!-- quiz: q02 revision: 1 -->
   - A. 把你写好的通知改得更口语、更亲切
   - B. 查出某种常用药按体重算的准确剂量
   - C. 说明某条法规第几条具体是怎么规定的
   - D. 整理一份论文清单，附上作者和年份
   > **答案A。** 改写润色的材料在你手上，改得不好一眼就看得出来，属于放心外包。B、C是硬事实，错了有代价；D听起来像“整理”，但作者和年份要它凭空生成，正是它容易编的地方（第9章）。这三类都得你兜底。

3. **[进阶·误区题]** 有人说：“写作是它的强项，所以让它写的产品介绍邮件可以直接发出去。”最准确的纠正是？ <!-- quiz: q03 revision: 1 -->

   - B. 不行，AI写的文字一律要人从头到尾重写一遍才能用
   - C. 风格可以放心，但发之前要再查一遍错别字和标点
   - D. 文字可以用，但参数、价格、获奖记录要单独核

4. **[进阶·误区题]** “我跟它聊了一下午，它肯定记住我是谁、喜欢什么了。”哪种说法最准确？ <!-- quiz: q04 revision: 1 -->
   - A. 只要还是同一个账号，模型就会把聊过的内容学进参数
   - B. 模型本身记不住，但产品的记忆功能可能存下一些
   - C. 模型本身有长期记忆，只是要付费套餐才会打开这个能力
   - D. 什么都不会留下，关掉对话后任何产品都不可能再用到

5. **[基础·情景题]** 你第一次用AI帮忙，想要一个靠谱的起步策略，下面哪个最好？ <!-- quiz: q05 revision: 1 -->
   - A. 先拿它当搜索引擎，只问那些有标准答案的事实问题
   - B. 让它把活推到70分，核对事实和拍板留给自己
   - C. 从最重要的决定开始用，最能看出它的真实水平
   - D. 先只让它陪聊，不交真正的活，熟悉一两个月再说
