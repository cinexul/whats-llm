前面九章讲的是模型“是什么、怎么运转”：它一个词一个词地往下接（第4章），生成时不核对真假，所以有时会很认真地编（第9章）；模型本体也没有跨对话的记忆（第3章）。

可当你真的打开对话框，手指放在键盘上，最先碰到的问题是：我该把它当成什么？无所不知的专家，搜索引擎，还是帮我做事的助理？想错了，要么不敢用，白白浪费；要么太放心，被它带错了还不知道。

这一章不讲新原理，只帮你把心态摆正。一个比喻就够了：把它当成一个很博学、但偶尔会一本正经地胡说的实习生。

## 一、它最像谁：一个“博学但会胡说的实习生”

想象公司给你派来一个实习生，有这么几个特点：

| 这个实习生 | 对应到模型 |
| --- | --- |
| 读过的书多得惊人 | 训练时学进参数的海量知识（第2章） |
| 手脚快、不喊累、不抱怨 | 你让它写十版它就写十版，凌晨三点也在 |
| 特别能说、特别自信 | 它追求“听起来顺”，措辞总是流畅笃定（第4章） |
| 但有时会很认真地乱编 | 不知道时未必说“我不会”，可能顺口编出一个像样的假答案（第9章） |
| 记不住昨天交代的事 | 模型本体没有跨对话记忆；新对话里它知道什么，取决于产品这次带进来了什么（第3章） |
| 不懂你心里真正想要什么 | 你没说清的，它只能猜（第11章要解决的就是这个） |

这个比喻要两半一起记：“博学”和“会胡说”。只记“博学”，你会盲信它，把它当权威；只记“会胡说”，你会怕它，什么都不敢交给它。其实两样都是真的：它知道的比你多，但它说的话要你把关。你最好把自己当成**带实习生的人**：活可以放手让它做，但署名和后果是你的，最后那一眼要你自己看。

当然，它不是真的人，没有意图，不会偷懒，也不会故意骗你。“实习生”只是个帮你把握分寸的比方，让你既不高估它，也不低估它。

## 二、可以放心外包的活vs必须你兜底的活

有了这个分寸，最实用的一步是分清哪些活能放手交给它、哪些活要你盯着。分界线接着第9章来：答案就在你给的材料里、错了一眼看得出的活，放心交；要它凭空给出硬事实、错了有代价的活，你要兜底。

| | 可以放心外包 | 必须你兜底 |
| --- | --- | --- |
| 典型任务 | 改写润色、换种说法、起草初稿、列提纲、头脑风暴、总结你贴进去的材料、翻译、解释一个概念 | 关键数字、引用出处、人名日期、法律医疗财务结论、对外发布的事实性内容 |
| 为什么 | 要么答案就在你给的上下文里，要么错了你一眼看得出、改起来也快 | 它可能编得很像真的（第9章），错了的代价却要你来承担 |
| 你的角色 | 说清要求，收到后检查 | 自己再查一遍，确认了才算数 |

两个对照例子：

```text
放心外包:
   "把这段300字的通知,改写得更口语、更亲切,给家长看。"
   —— 材料在手,风格类的活,错了你一眼看得出。

必须兜底:
   "我国某项税收政策的具体起征点是多少?"
   —— 这是硬事实,它可能随口就编(第9章)。要么让它给出处、你自己去核,
      要么直接到政府部门的官方网站查。
```

最容易出错的，是看起来能放心外包、里面却夹着硬事实的活。比如让它“写一封介绍公司产品的邮件”：写作是它的强项，可它一旦顺手写进某个参数、价格或获奖记录，那部分就变成了硬事实。收到稿子后，先把里面具体的数字、名称、日期、引用挑出来单独核对（方法见第9章），其余的文字再放心用。

## 三、第一次该期待什么、别期待什么

期待对了，就不会失望；期待错了，要么以为它什么都会，结果吃了亏，要么以为它什么都不行，结果错过了。

可以期待它做到的：

- 听懂自然语言。用大白话提要求就可以，不用学什么命令或咒语。
- 很快给出能用的初稿。写邮件、列大纲、改文风、解释概念，常常一次就有个像样的版本。
- 不厌其烦地改。不满意就让它再写一版、换个角度、改长改短，它不会嫌烦。
- 根据你给的材料做事。把资料贴给它，让它总结、对照、提取，通常比较可靠（第12章细讲）。

别指望它做到的：

- 句句是真。它会胡说，越流畅越要多留意（第9章）。
- 记得昨天。新对话默认从零开始；就算产品开了记忆功能，带进来的也只是保存下来的那部分（第3章）。
- 知道最新消息。它的知识有截止日期（第9章），问近期的事，别信它不查资料直接给的答案。
- 猜中你的心思。你没说清的要求，它只能靠猜（第11章教你把要求说清楚）。

一个好用的起步办法：先用它来省力，别急着用它来下定论。让它帮你把活从0推到70分，起草、整理、找思路，这部分它又快又好；最后那30分，核对事实、决定取舍、署名负责，留给你自己。

## 四、“它有没有记忆”，第一次就要弄清楚

新手第一次用，几乎都会有同一个误会：聊得投入了，不知不觉就觉得它认识我了，记得我们聊过什么了。

第9章讲过：模型本体没有跨对话记忆，你觉得它“记得”的，是产品替它放回上下文的那部分。截至2026年10月，Claude、ChatGPT等不少产品都有项目和记忆一类的功能：项目让你把资料和要求放在一起反复用，记忆则把你的偏好和聊过的要点存下来，有的会从聊天里自动挑出要记的内容，而且可能默认开着。

落到第一次对话上，有三条：

- 别假设它记得。需要它知道的背景，就在这次对话里说清楚。
- 想让它长期记住的偏好，用产品的记忆或项目功能（第13章细讲）。
- 不想被记住的内容，用临时对话（有的产品叫无痕对话），或者先关掉记忆再聊；隔一阵子去设置里看看它存了什么，过时的、不对的删掉。各家的叫法、默认设置和删除方式不一样，以官方说明为准；哪些内容根本不该发给AI，见第37章。

把“它默认没有记忆”当作起点，就不会奇怪它怎么一下子像不认识你了；同时也要知道，开着记忆的产品，可能比你以为的记得更多。

## 五、常见误解，集中纠正

| 误解 | 实际 |
| --- | --- |
| 它无所不知，可以当权威信 | 它博学但会胡说；知道的比你多，但说的话要你把关 |
| 它什么都靠不住，不敢交活给它 | 改写、起草、整理、总结材料这类活又快又好；要兜底的只是硬事实 |
| 它像搜索引擎，给的就是查到的事实 | 它是现算生成的（第2章），不是查的；流畅不等于正确（第4、9章） |
| 写作类的活完全不用核对 | 写作里夹带的数字、名称、出处仍要你核对 |
| 聊过就等于它“认识”我了 | 模型本体没有跨对话记忆；产品的记忆功能会把存下的信息放回上下文，不是模型自己记得 |
| 它该能猜到我想要什么 | 没说清的它只能猜，把要求说清楚是你的事（第11章） |

## 小结

- 把它当成一个很博学、但偶尔一本正经胡说的实习生，“博学”和“会胡说”两半一起记。你是带实习生的人：活可以放手让它做，署名和后果是你的。
- 改写、起草、整理、总结材料可以放心外包；关键数字、出处、人名日期、法律医疗财务等硬事实必须你兜底，写作里夹带的硬事实也一样。
- 可以期待它听懂大白话、很快出初稿、不厌其烦地改、根据材料做事；别指望它句句是真、记得昨天、知道最新消息、猜中你的心思。
- 先用它省力，把活推到70分；最后30分，核对事实和做决定，留给自己。
- 默认它没有记忆。想长期记住偏好，用产品的记忆或项目功能（第13章）；不想被记住的，用临时对话或关掉记忆，并定期查看、删除已存的记忆。

下一章讲“它猜不到你想要什么”这个问题：怎么把“我想要什么”说清楚，也就是提示词的结构。

1. **[基础·概念题]** 本章建议把模型当成什么来用，分寸最稳？ <!-- quiz: q01 revision: 3 -->
   - A. 一个查得很快的搜索引擎，给的多是查到的现成事实
   - B. 一位知识渊博的专家顾问，专业问题上可以直接采信
   - C. 一个读书很多、但偶尔会一本正经编内容的实习生
   - D. 一个只会机械拼词的程序，正经的活最好别交给它
   > **答案C。** “博学”和“会胡说”两半要一起记：它知道的比你多，但它说的话要你把关。A把它当成“查”出来的，第2章讲过它是现算生成的，流畅不等于正确；B只记住了“博学”，容易盲信；D只记住了“会胡说”，会白白浪费改写、起草这些它很擅长的活。

2. **[基础·概念题]** 下面哪类任务，最适合“放心外包”给它？ <!-- quiz: q02 revision: 3 -->
   - A. 把你写好的通知改得更口语、更亲切
   - B. 查出某种常用药按体重算的准确剂量
   - C. 说明某条法规第几条具体是怎么规定的
   - D. 整理一份论文清单，附上作者和年份
   > **答案A。** 改写润色的材料在你手上，改得不好一眼就看得出来，属于放心外包。B、C是硬事实，错了有代价；D听起来像“整理”，但作者和年份要它凭空生成，正是它容易编的地方（第9章）。这三类都要你把关。

3. **[进阶·误区题]** 有人说：“写作是它的强项，所以让它写的产品介绍邮件可以直接发出去。”最准确的纠正是？ <!-- quiz: q03 revision: 2 -->
   - A. 没问题，文字通顺、语气得体的邮件就可以放心发出
   - B. 不行，AI写的文字一律要人从头到尾重写一遍才能用
   - C. 风格可以放心，但发之前要再查一遍错别字和标点
   - D. 文字可以用，但参数、价格、获奖记录要单独核
   > **答案D。** 任务看起来像放心外包，里面却夹着硬事实。把稿子里的数字、名称、日期、引用挑出来单独验，其余文字可以放心用。A只看到“写作是强项”，忘了流畅不等于正确（第4、9章）；B矫枉过正；C查的是表面问题，真正的风险在硬事实。

4. **[进阶·误区题]** “我跟它聊了一下午，它肯定记住我是谁、喜欢什么了。”哪种说法最准确？ <!-- quiz: q04 revision: 2 -->
   - A. 只要还是同一个账号，模型就会把聊过的内容学进参数
   - B. 模型本身记不住，但产品的记忆功能可能存下一些
   - C. 模型本身有长期记忆，只是要付费套餐才会打开这个能力
   - D. 什么都不会留下，关掉对话后任何产品都不可能再用到
   > **答案B。** 模型本体没有跨对话记忆。但Claude、ChatGPT等产品可能提供记忆功能，有的会从聊天里自动提取，还可能默认开启；存下的内容会在之后的对话里放回上下文。A把这件事当成了训练，聊天通常不会改动模型参数；C把产品功能当成模型能力；D说过头了，开着记忆的产品确实可能把信息带进新对话。具体怎么存、怎么删，以官方文档为准。

5. **[基础·情景题]** 你第一次用AI帮忙，想要一个稳妥的起步策略，下面哪个最好？ <!-- quiz: q05 revision: 3 -->
   - A. 先拿它当搜索引擎，只问那些有标准答案的事实问题
   - B. 让它把活推到70分，核对事实和做决定留给自己
   - C. 从最重要的决定开始用，最能看出它的真实水平
   - D. 先只让它陪聊，不交真正的活，熟悉一两个月再说
   > **答案B。** 这就是本章的核心做法：先用它省力，别急着用它定论。起草、整理、找思路它又快又好；核对事实、做决定、署名负责是你的事。A正好把它用在最容易出幻觉的地方；C把定论交给它，风险最大；D太保守，白白浪费了它的长处。

6. **[基础·操作题]** 找一件你手头的真实小任务（如改写一段通知、给一封邮件起草）。先想清楚：这件事属于“放心外包”还是“必须兜底”？如果两者都沾，把其中的“硬事实”部分单独圈出来。然后再交给AI。 <!-- quiz: q06 revision: 2 -->
   > **该观察到：** 大多数日常任务的“风格部分”（怎么写得更顺、更得体）可以放心外包；真正需要你兜底的，往往只是夹在里面的少数**硬事实**（数字、名称、日期、出处）。亲手圈一次，你就养成了“收到稿子先挑硬事实来核”的习惯。圈出来要核的事实，能查官方就以官方为准。
