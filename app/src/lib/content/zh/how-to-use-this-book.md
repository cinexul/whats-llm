## 一、这本书想带你去哪里

读完它，你会获得四样东西，由浅入深：

| | 你将学会 | 对应部分 |
| --- | --- | --- |
| ① 看懂 | 大模型到底是什么、为什么能接话、为什么会说错——不再被一堆名词唬住 | 第一部分 |
| ② 会用 | 把AI用到日常、学习、工作里，问得准、喂得对、不被带偏 | 第二部分 |
| ③ 看清 | 模型 / 产品 / API / Agent、RAG、本地模型……一张地图认清整个工具生态 | 第三部分 |
| ④ 会做 | 用**Claude Code和Codex**这两个主流工具，做出你自己的项目 | 第四、五部分 |

最后还有第六部分，讲**风险与边界**——什么能喂给AI、什么绝对不能，怎么不烧钱、不踩雷、负责任地用。

> **要点：** 这不是一本“AI使用技巧大全”，而是想让你**真正理解AI是怎么回事**，从而自己判断“什么时候能信它、什么时候得自己把关”。理解了原理，技巧自然就有了。

## 二、两种读法，按需取用

你不一定要从头读到尾。挑一条适合你的线：

- **只想“会用”**：读**第一、二部分**（基础 + 日常使用），再跳到**第六部分**（风险）。这就够你把AI用得又顺又稳。
- **想“动手做东西”**：在上面的基础上，继续读**第三、四、五部分**（工具生态 → 编程实战 → 六个实战项目），一步步做出个人网站、文档工具、会议纪要助手，甚至给自己的程序接上AI。

无论哪条线，建议**第一部分别跳**——它是整本书的地基，后面所有“为什么这样用”都建在它上面。

## 三、配套怎么用

- **每章末尾的「小测验」**：一般是6道题，以概念题、误区题、情景题为主，最后常有一道动手操作或观察的练习（个别章节还有计算题等）。选择题作答后，阅读器会显示答案和解析；操作/观察题没有唯一答案，可以展开参考要点。别只看对错，解析里讲的“为什么错、什么情况下容易这么想”才是重点。
- **术语表（附录A）**：中日英三语对照，看到不懂的词随时来查。
- **提示词模板（附录B）**：日常、工作、学习、编程等场景的“拿来即填”模板。
- **中日英三语**：本书有中文、日文、英文三个版本，点阅读器顶部的「**中文 / 日本語 / English**」即可一键切换，内容一一对应。正文里关键术语**首次出现会用括号附上英文**（如 上下文窗口（context window）），方便你将来查英文资料。
- 阅读器还支持**左侧目录跳转、全文搜索、给文字划重点和写笔记**，读到哪、标过什么都会自动保存。

## 四、一个贯穿全书的心态

如果这本书只能让你记住两句话，那就是这两句——

1. **AI很能干，但会“一本正经地说错”。** 流畅、自信的表达不能证明内容正确；模型也会经过对齐训练、使用检索和验证工具，但这些都不保证零错误。所以**重要的事实、数字、引文，永远自己复核**。把它当一个聪明、好用、但偶尔信口开河的助手，而不是一本永远正确的百科全书。
2. **当前上下文、已保存的历史和产品记忆是不同的东西。** 你看到的“它记得我”，绝大多数是**产品层每次帮你把信息重新喂回去**，而不是模型本体真的记住了（这一点第3、9章会讲透）。理解了这条，很多“它怎么忘了”“它怎么又记得”的困惑就都解开了。

> **要点：** 带着“结果要验证、记忆有边界”这两点去读后面每一章，你会发现全书的方法和提醒，几乎都是在教你如何与这两条性质共处、并把AI用好用稳。

- 这是一本面向普通人的**大模型基础 + AI工具实战**手册，**不需要编程基础**。

- 两种读法：只想会用走“第一、二、六部分”；想动手做继续“第三、四、五部分”。
- 善用每章**小测验**、**术语表**、**提示词模板**，以及顶部的**中日英三语切换**。
- 全程记住两句话：**AI会自信地说错（重要的自己核）**；**记忆有边界（要区分上下文、历史与产品保存的信息）**。
