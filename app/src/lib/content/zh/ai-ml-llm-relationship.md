“AI会取代人类吗？”“AI已经有意识了吧？”“听说AI连围棋世界冠军都赢了，那它岂不是什么都会？”——只要“AI”两个字一出现，话题总会瞬间被拉到很大、很玄。

但你有没有发现：人们口中的“AI”，其实是一堆完全不同的东西。会下棋的是AI，会聊天的是AI，手机相册里“自动识别出这是猫”也是AI，垃圾邮件被拦下来还是AI。它们看起来差了十万八千里，凭什么共用一个名字？

这一章不讲玄的。我们只做一件事：**给你一张层层嵌套的“套娃图”**，把人工智能（AI）、机器学习（machine learning）、深度学习（deep learning）、大模型（LLM）这四个最常听到、又最容易搞混的词，一次摆清楚。看懂这张图，你就能给身边任何一个“AI”准确地对号入座——也不会再把“会下棋”和“会聊天”当成同一回事。这是理解后面所有章节的地基。

## 一、先认清一件事：它们是“套娃”，不是“并列”

很多人第一次听这几个词，会以为它们是**并排的四样东西**，像四个牌子的手机让你挑一个。

**不是的。** 它们是**一层套一层、由大到小**的包含关系——像俄罗斯套娃，大的里面装着小的：

```text
┌───────────────────────────────────────────────┐
│ 人工智能 AI(最大的圈:让机器做"需要智力"的事)   │
│   ┌───────────────────────────────────────┐   │
│   │ 机器学习 ML(让机器从数据里自己找规律)  │   │
│   │   ┌───────────────────────────────┐   │   │
│   │   │ 深度学习 DL(用"很多层"来学)    │   │   │
│   │   │   ┌───────────────────────┐   │   │   │
│   │   │   │ 大模型 LLM(专攻语言)  │   │   │   │
│   │   │   └───────────────────────┘   │   │   │
│   │   └───────────────────────────────┘   │   │
│   └───────────────────────────────────────┘   │
└───────────────────────────────────────────────┘
```

读这张图的正确方式是：**越往里，范围越窄、越具体**。大模型是深度学习的一种，深度学习是机器学习的一种，机器学习是人工智能的一种。反过来说，你天天聊天用的那个大模型，只是最里面那个最小的套娃——是整个AI世界里**一个很具体的小角落**，绝不是“全部AI”。

> **要点：** 记住一句话就够：**大模型 ⊂ 深度学习 ⊂ 机器学习 ⊂ 人工智能**。后面三节我们从外往里，一层层把每个圈讲清楚：它是什么、为什么需要它、人们常在哪里误会它。

## 二、四个圈，逐层拆开

我们用一张对照表先建立全局感，再逐个解释。

| 层次（从大到小） | 一句话是什么 | 一个生活例子 | 它和外一层的关系 |
| --- | --- | --- | --- |
| 人工智能（AI） | 让机器去做“原本得靠人脑”的事 | 下棋、看图识物、路线规划、垃圾邮件过滤 | 最大的总称，下面所有的都算AI |
| 机器学习（machine learning） | 不靠人写死规则，让机器**从数据里自己找规律** | 看了几万张猫狗照片后，自己学会区分猫狗 | AI的一种**做法**（不是唯一做法） |
| 深度学习（deep learning） | 机器学习里的一种，用**很多层**的计算网络来学 | 今天的看图、语音、翻译大多靠它 | 机器学习里**特别能打**的一支 |
| 大模型（LLM） | 深度学习的一种，**专门学语言**的超大模型 | Claude、ChatGPT背后的内核 | 深度学习里**主攻“文字接龙”**的那一类 |

### 第①层 人工智能（AI）：一个“目标”，不是一种“技术”

**人工智能**是这四个里最大、也最老的词。它指的是一个**目标**：让机器去完成“原本需要人的智力”才能做的事——认人脸、听懂话、下棋、开车、推荐你可能想买的东西。

关键在于：AI是个**总称**，底下塞着许许多多种**完全不同**的技术。

- 早年的很多AI，是程序员**一条条把规则写死**的：“如果棋盘是这样，就走这一步”。这类AI一行“自己学”的能力都没有，全靠人提前想好。
- 直到今天，“AI”这个标签底下依然五花八门：有会下棋的、有会看图的、有会聊天的。它们**内部原理可以天差地别**，只是都被归进了“让机器变聪明”这个大目标里。

> **为什么需要这个词？** 因为它是一面“大旗”，方便人们谈论“让机器代替智力劳动”这件事。但也正因为它太大，**“AI”几乎什么都不精确说明**——听到“这是个AI”，你其实还不知道它到底会干什么、怎么干的。所以下面三层，就是来给“哪一种AI”做精确定位的。

### 第②层 机器学习（machine learning）：从“人写规则”到“机器找规律”

这是整张图里**最关键的一次转弯**，务必理解。

传统程序是这样的：人把规则**一条条写清楚**，机器照着执行。但有些事，规则根本写不清楚——你能用文字把“猫长什么样”精确描述到让电脑认出每一只猫吗？耳朵尖？有胡须？那狐狸呢？

**机器学习**换了个思路：**不写规则了，改喂数据**。给机器看几万张标好“猫”和“狗”的照片，让它**自己**去总结“猫和狗到底差在哪”。学完之后，你给它一张没见过的新照片，它也能判断个八九不离十。

```text
传统程序: 人想好规则  →  写进代码  →  机器照做
机器学习: 给一堆例子  →  机器自己找规律  →  学出一套"判断的本事"
```

> **常见误解：** “机器学习，就是机器像人一样理解了道理。”它从数据中学习规律和表示，这些可以支持有用的预测和推理。但答对问题本身，不证明它具有人类式的理解；学到的规律也可能在陌生情况中失效。数据质量、训练方法和具体任务都会影响错误，不能用一句话概括AI所有毛病的原因（见第9章）。

### 第③层 深度学习（deep learning）：用“很多层”来学

机器学习有很多种具体方法，**深度学习**是其中近十几年**应用广泛**的一支，今天的看图、语音、翻译、聊天，绝大多数都靠它。

它的名字里那个“深”字，指的是它用的“计算网络”——**神经网络（neural network）**——叠了**很多很多层**。数据从第一层进去，一层层往上传，每一层都从中提炼出更抽象一点的信息。多层结构有助于学习复杂规律，但增加层数不保证效果更好；数据、网络设计和训练方法同样重要。

- **神经网络（neural network）**的设计受到生物神经元的粗略启发，但人工单元执行的是数字运算，并不是人脑的精细模拟。仅凭这个名字，不能判断一个系统是否具有人类式的思维或情感。
- 之所以这些年深度学习突然厉害起来，靠的是三样东西同时凑齐了：**数据多了**（互联网上海量内容）、**算力强了**（专门的芯片）、**方法成熟了**。

> **实际会怎么遇到：** 你几乎遇不到“深度学习”这个词单独蹦出来——它藏在产品背后。但当有人说某个AI“是基于神经网络的”“是深度学习做的”，你心里要清楚：这说的是它**用了哪种技术路子**，属于机器学习这个大圈里的一支，**还没说到它具体是干什么的**。

### 第④层 大模型（LLM）：深度学习里“专攻语言”的那一类

终于到最里面这个小套娃了——也是这本书的主角。

**大模型**，全称**大语言模型（large language model，简称LLM）**，是深度学习的一种，**专门用来处理语言（文字）**。它从海量文本里学会了“词和词之间怎么接续”，于是能写文章、答问题、翻译、写代码。Claude、ChatGPT、Gemini的内核，都是这一类模型。

顺带说一句用词：中文里的“大模型”有时也泛指专门处理图像的视觉大模型，或同时处理文字、图像、声音的多模态大模型。本书说“大模型”，如果没有特别说明，指的都是大语言模型。

注意它的定位：

- 它是深度学习里**以语言为中心的一个分支**。计算机视觉关注图像，另有方法处理语音，但这些分类可以重叠：许多现代模型具有**多模态**能力，也就是结合文字、图像、声音等信息。会聊天并不自动说明某个模型还会什么；要看具体模型和产品支持哪些能力（见第18章）。
- “大”大在哪、它内部到底怎么运作、为什么会出错——这些是**第2章到第9章**整整一个部分要展开讲的。这里你只需要先把它**在地图上的位置**钉死：**它在最里圈，是AI的一个很小、很具体的子类。**

> **要点：** 把大模型摆回它的位置，你会立刻对很多夸张说法“脱敏”：“AI觉醒了”“AI无所不能”——这些说的好像是最外圈那个无边无际的“AI”，可你实际在用的，只是最里圈那个**“专门接文字的语言模型”**。它很强，但它的本事是有边界、有来路的。

## 三、那Claude、ChatGPT到底算第几层？

这是最容易卡住的地方，单独说清楚。

你可能会问：照你这么说，Claude、ChatGPT是“大模型”咯？——**严格讲，它们是“大模型的产品化”，比纯粹的大模型还要再往外一点点。**

打个比方：大模型像一位**很有本事的厨师**（会做菜的“手艺”），而ChatGPT、Claude的App是一家**餐厅**——把厨师请进来，配上菜单、餐桌、服务员，你才能“走进去点菜”。你日常点开就聊的那个聊天界面，是**产品**；它背后那个真正“会接话”的内核，才是**大模型**。

| 你说的 | 它其实是 | 在套娃图里 |
| --- | --- | --- |
| “我用ChatGPT” | 一个**产品**（给人用的聊天界面） | 内核是大模型，外面还包了一层“产品” |
| “ChatGPT的内核是GPT” | GPT才是那个**大模型** | 最里圈那个小套娃 |
| “Claude” | 既指模型系列，也常指它的产品 | 看语境，可能指内核，也可能指那家“餐厅” |

模型、产品、API、Agent这几层到底怎么区分，我们留到**第17章**用一整章讲透。这里你只要记住：**你天天用的“AI聊天产品”，是在最里圈那个大模型外面，又包了一层“给人用的包装”**。它依然稳稳待在AI这张大地图的一个小角落里。

## 四、常见误解，集中纠正

| 误解 | 实际 |
| --- | --- |
| AI = 一个无所不能的“电脑大脑” | AI是一大类技术的总称，底下全是各管一摊的**专用**本事；没有哪个AI“什么都会” |
| 会下棋的AI和会聊天的AI是一回事 | 它们内部原理可以**完全不同**，只是都被叫“AI”；一个擅长算棋，一个擅长处理语言；一种能力不自动意味着另一种能力 |
| 大模型 = AI的全部 | 大模型只是AI最里圈的**一个小子类**（深度学习里专攻语言的一支） |
| 机器学习是机器“自己想明白了” | 它从数据里**学习规律**；预测有用，本身不证明它像人一样理解 |
| 神经网络“像人脑一样思考” | 设计受到神经元的**粗略启发**，人工单元做的是数字运算，并非人脑的精细模拟 |
| ChatGPT就是“那个大模型” | ChatGPT是**产品**，内核才是大模型（GPT）；中间隔着一层“给人用的包装”（第17章） |

## 小结

- 这四个词是**套娃关系**，不是并列：**大模型 ⊂ 深度学习 ⊂ 机器学习 ⊂ 人工智能**，由里到外、越来越宽。
- **人工智能（AI）** 是最大的总称——一个“让机器做智力活”的目标，底下塞着各种**完全不同**的技术。
- **机器学习** 是AI的一种做法：不写死规则，**让机器从数据里自己找规律**（但学到规律，不等于证明它像人一样理解）。
- **深度学习** 是机器学习里应用广泛的一支，用**很多层的神经网络**来学；人工单元做数字运算，设计受到神经元的粗略启发。
- **大模型（LLM）** 是深度学习里**专攻语言**的一类——你用的AI聊天产品，内核就是它，但它只是AI世界一个**很小的角落**。
- 你日常用的Claude、ChatGPT是大模型的**产品化**，比裸模型又往外包了一层（第17章细讲）。

下一章，我们就钻进最里圈那个小套娃，看看**大模型到底“大”在哪、它内部那“亿万个旋钮”是什么意思**，以及一个最该破除的误会——**它不是一个能查的数据库**。

## 小测验

> 共6题，涵盖概念、误区、情景、操作四类。答案与解析在每题下方的引用块里——先自己想，再对照。

1. **[基础·概念题]** 下面哪句话最准确地描述了这四个词的关系？ <!-- quiz: q01 revision: 1 -->
   - A. 四个词并列，是四种互不相干的技术，用的时候挑一种
   - B. 大模型包含深度学习，深度学习包含机器学习，机器学习包含AI
   - C. 大模型属于深度学习，深度学习属于机器学习，机器学习属于AI
   - D. AI和机器学习是一回事，深度学习和大模型是它下面的两类
   > **答案C。** 这是一组“套娃”式的包含关系：大模型在最里面、最具体，AI在最外面、最宽泛。B的四个词顺序没错，但包含方向说反了，是大圈装着小圈。A把嵌套误当成并列。D把AI和机器学习画了等号，可AI还包括人写规则的老办法；它也把深度学习和大模型说成平级，其实大模型是深度学习里的一支。

2. **[基础·概念题]** “机器学习”和传统程序最根本的区别是什么？ <!-- quiz: q02 revision: 1 -->
   - A. 传统程序靠人写好规则，机器学习让机器从数据里自己找规律
   - B. 机器学习不需要人参与，程序写好以后会自己越用越聪明
   - C. 机器学习先把大量数据存下来，用的时候再去里面查找匹配
   - D. 传统程序只会照做，机器学习能像人一样真正理解问题含义
   > **答案A。** 这是整张图里最关键的一次转弯：从“人写规则”变成“喂数据、让机器自己总结规律”。B不对：数据要人准备，训练方法要人设计，而且常见的模型训练完参数就固定了，不会在使用中自己变聪明（第2章）。C把“学规律”和“存数据、查数据”混为一谈（第2章会专门纠正这一点）。D说过头了：学到有用的规律，不等于证明它像人一样理解。

3. **[进阶·误区题]** “会下围棋赢世界冠军的AI，肯定也很会聊天、什么都会”——这个想法错在哪？ <!-- quiz: q03 revision: 1 -->
   - A. 下棋系统规模还不够大，换成更大的模型就什么都会了
   - B. 会下围棋说明它已有通用智力，只是还没人教它说话
   - C. 围棋AI其实不算AI，它只是一套人写死规则的程序
   - D. 两类系统可能用不同方法训练，围棋强不代表也会聊天
   > **答案D。** “AI”是个大总称。为赢围棋而训练的系统，和为生成语言而训练的模型，设计和能力可能完全不同；某些方法可以共用，但一项任务做得好，不证明另一项也行。A以为“够大就什么都会”，B把下棋本事当成了通用智力，这两种都是常见的过度推断。C也不对：顶尖的围棋程序正是用机器学习训练出来的，并非人写死的规则。

4. **[基础·误区题]** “我用的ChatGPT，就是那个‘大模型’本身”——这句话哪里不够准确？ <!-- quiz: q04 revision: 1 -->
   - A. 没问题，ChatGPT和GPT只是同一样东西的两种叫法
   - B. ChatGPT是产品，内核是大模型，外面包了一层产品功能
   - C. ChatGPT没用大模型，它靠人写好的大量问答规则运行
   - D. 大模型只是ChatGPT里的一个插件，遇到难题时才会调用
   > **答案B。** 你点开就聊的是产品（像“餐厅”），真正会接话的内核（像“厨师的手艺”）才是大模型。日常混着说问题不大，但心里要分清这两层（第17章专门讲模型、产品、API、Agent的区别）。A正是题目里的误解；C说反了，它的内核就是大模型；D把主次颠倒了，大模型是核心，不是偶尔调用的插件。

5. **[基础·情景题]** 朋友指着手机相册说：“它能自动认出哪些照片里有猫，这也是AI吗？它和我聊天用的AI是一个吗？”你该怎么回答最准确？ <!-- quiz: q05 revision: 1 -->
   - A. 都是AI，而且手机里认猫和聊天用的一定是同一个模型
   - B. 认猫不算AI，只是按颜色和形状去匹配的普通功能
   - C. 都算AI，但认猫多属计算机视觉，聊天靠的是语言模型
   - D. 只有会聊天的才算AI，认图功能只能算是图像处理
   > **答案C。** 两者都属于AI，只是任务不同：找出照片里的猫是计算机视觉任务，聊天用到语言模型。现在也有多模态模型把看图和语言结合起来，所以具体某个产品用了什么，要看它实际支持什么。A把“都是AI”推成了“一定是同一个模型”；B和D武断地把其中一类排除在AI之外。

6. **[基础·操作/观察题]** 环顾你自己一天会用到的“AI”：手机的人脸解锁、相册的物体识别、输入法的联想、地图的路线规划、垃圾短信拦截、你常用的聊天AI……挑出三四个，试着说出每一个**大致落在套娃图的哪一圈**，以及“它属于‘会聊天’那一支吗”。 <!-- quiz: q06 revision: 1 -->
   > **该观察到：** 这些功能中许多会用到AI，但不都依靠大语言模型。人脸解锁和物体识别常用计算机视觉；路线规划也可能用传统搜索算法；垃圾过滤、输入联想则可采用多种方法，包括语言模型。仅凭产品名称，不能确定内部实现。练习的重点是问清它做什么、用了哪类技术，而不是把“AI”等同于“什么都会”。
