“AI会取代人类吗？”“AI已经有意识了吧？”“AI连围棋世界冠军都赢了，那它岂不是什么都会？”只要说到AI，话题很容易一下子变得又大又玄。

可人们口中的“AI”其实是一堆很不一样的东西：会下棋的是AI，会聊天的是AI，手机相册自动认出“这是猫”也是AI，拦下垃圾邮件的还是AI。它们差得这么远，为什么共用一个名字？

这一章只做一件事：用一张“套娃图”，把人工智能（AI）、机器学习（machine learning）、深度学习（deep learning）、大模型（LLM）这四个最常听到、也最容易混的词摆清楚。看懂这张图，你就能给身边的各种“AI”对号入座，也不会再把“会下棋”和“会聊天”当成一回事。

## 一、先认清一件事：它们是“套娃”，不是“并列”

很多人以为这四个词是并排的四样东西，像四个牌子的手机让你挑一个。其实它们是一层套一层的包含关系，像俄罗斯套娃，大的里面装着小的：

```text
┌───────────────────────────────────────────────┐
│ 人工智能 AI(最大的圈:让机器做"需要智力"的事)   │
│   ┌───────────────────────────────────────┐   │
│   │ 机器学习 ML(让机器从数据里自己找规律)  │   │
│   │   ┌───────────────────────────────┐   │   │
│   │   │ 深度学习 DL(用"很多层"来学)    │   │   │
│   │   │   ┌───────────────────────┐   │   │   │
│   │   │   │ 大模型 LLM(专攻语言)  │   │   │   │
│   │   │   └───────────────────────┘   │   │   │
│   │   └───────────────────────────────┘   │   │
│   └───────────────────────────────────────┘   │
└───────────────────────────────────────────────┘
```

越往里，范围越窄、越具体：大模型是深度学习的一种，深度学习是机器学习的一种，机器学习是人工智能的一种。你天天聊天用的大模型，只是最里面那个最小的套娃，是AI世界里一个很具体的角落，不是AI的全部。

> **要点：** 一句话就能记住这张图：大模型 ⊂ 深度学习 ⊂ 机器学习 ⊂ 人工智能。

## 二、四个圈，逐层拆开

先用一张表看个全貌，再一个个解释。

| 层次（从大到小） | 一句话是什么 | 一个生活例子 | 它和外一层的关系 |
| --- | --- | --- | --- |
| 人工智能（AI） | 让机器去做原本要靠人脑的事 | 下棋、看图识物、路线规划、垃圾邮件过滤 | 最大的总称，下面的都算AI |
| 机器学习（machine learning） | 不靠人写死规则，让机器从数据里自己找规律 | 看了几万张猫狗照片后，学会区分猫狗 | AI的一种做法（不是唯一做法） |
| 深度学习（deep learning） | 机器学习的一种，用很多层的计算网络来学 | 今天的看图、语音、翻译大多靠它 | 机器学习里用得最广的一支 |
| 大模型（LLM） | 深度学习的一种，专门学语言的超大模型 | Claude、ChatGPT背后的内核 | 深度学习里主攻“文字接龙”的一类 |

### 第①层 人工智能（AI）：一个“目标”，不是一种“技术”

人工智能是这四个词里最大、也最老的一个。它指的是一个目标：让机器做原本需要人的智力才能做的事，比如认人脸、听懂话、下棋、开车、推荐你可能想买的东西。

AI是个总称，底下是许多完全不同的技术。早年很多AI是程序员一条条写死规则：“如果棋盘是这样，就走这一步”，它自己一点也不会学。今天“AI”这个标签下依然五花八门，会下棋的、会看图的、会聊天的，内部原理可以天差地别。

正因为这个词太大，听到“这是个AI”，你其实还不知道它会干什么、怎么干的。下面三层，就是用来说清“是哪一种AI”的。

### 第②层 机器学习（machine learning）：从“人写规则”到“机器找规律”

这是整张图里最关键的一次转弯。

传统程序是人把规则一条条写清楚，机器照着执行。可有些事的规则根本写不清：你能用文字把“猫长什么样”描述到让电脑认出每一只猫吗？耳朵尖？有胡须？那狐狸呢？

**机器学习**换了个思路：不写规则，改给数据。给机器看几万张标好“猫”和“狗”的照片，让它自己总结两者差在哪。学完以后，给它一张没见过的照片，它也能判断得大致不差。

```text
传统程序: 人想好规则  →  写进代码  →  机器照做
机器学习: 给一堆例子  →  机器自己找规律  →  学出一套"判断的本事"
```

要注意，机器学到的是数据里的规律。靠这些规律，它能做出有用的预测；但答对了题，不代表它像人一样懂了，碰到没见过的情况，学到的规律也可能不管用。它为什么会出错，第9章再细讲。

### 第③层 深度学习（deep learning）：用“很多层”来学

机器学习有很多具体方法，**深度学习**是近十几年用得最广的一支，今天的看图、语音、翻译和聊天大多靠它。

名字里的“深”，指它用的计算网络叠了很多层。这种网络叫**神经网络（neural network）**：数据从第一层进去，一层层往上传，每一层都提炼出更抽象一点的信息。层数多，能学会更复杂的规律，但光加层数不一定更好，数据、网络怎么设计、怎么训练也一样要紧。

神经网络的设计借鉴了生物神经元的大致样子，但它的“神经元”做的只是数字运算，不是在仿造人脑。光看这个名字，看不出一个系统有没有像人一样的思维或情感。

深度学习这些年突然厉害起来，是因为三样东西同时凑齐了：数据多了（互联网上的海量内容），算力强了（专门的芯片），方法也成熟了。

你很少会看到“深度学习”单独出现，它藏在产品背后。有人说某个AI“基于神经网络”“是深度学习做的”，说的是它用了哪种技术路子，还没说它具体能干什么。

### 第④层 大模型（LLM）：深度学习里“专攻语言”的那一类

终于到了最里面的小套娃，也是这本书的主角。

**大模型**全称大语言模型（large language model，简称LLM），是深度学习里专门处理语言（文字）的一类。它从海量文本里学会了词和词之间怎么接续，于是能写文章、答问题、翻译、写代码。Claude、ChatGPT、Gemini的内核都是这类模型。

顺带说一句用词：中文里的“大模型”有时也指处理图像的视觉大模型，或同时处理文字、图像、声音的多模态大模型。本书说“大模型”，没有特别说明时，指的都是大语言模型。

它在地图上的位置，有两点值得留意：

- 它是深度学习里以语言为主的一支。图像、语音各有别的处理方法，不过界线并不分明：现在不少模型是多模态的，文字、图像、声音都能处理。会聊天，不代表它别的也会，要看具体模型和产品支持什么（第18章）。
- 它“大”在哪、内部怎么运作、为什么会出错，是第2章到第9章要展开讲的。这里先记住它的位置：最里圈，AI里一个很具体的小类。

把大模型放回这个位置，很多夸张的说法就没那么吓人了。“AI觉醒了”“AI无所不能”，说的好像是最外圈那个无边无际的“AI”，可你实际在用的，是最里圈那个专门处理文字的语言模型。它很强，但本事有边界，也有来路。

## 三、那Claude、ChatGPT到底算第几层？

你可能会问：Claude、ChatGPT就是大模型吧？严格讲，它们是用大模型做成的产品，比纯粹的模型还要再往外一点。

打个比方：大模型像一位手艺很好的厨师，ChatGPT、Claude的App是一家餐厅，把厨师请进来，配上菜单、餐桌和服务员，你才能走进去点菜。你点开就聊的那个界面是产品；背后真正“会接话”的内核，才是大模型。

| 你说的 | 它其实是 | 在套娃图里 |
| --- | --- | --- |
| “我用ChatGPT” | 一个产品（给人用的聊天界面） | 内核是大模型，外面包了一层产品 |
| “ChatGPT的内核是GPT” | GPT才是那个大模型 | 最里圈那个小套娃 |
| “Claude” | 既指模型系列，也常指它的产品 | 看语境，可能指厨师，也可能指餐厅 |

模型、产品、API、Agent这几层怎么区分，第17章会用一整章来讲。这里只需要知道：你天天用的AI聊天产品，是在大模型外面又包了一层给人用的包装。

## 四、常见误解，集中纠正

| 误解 | 实际 |
| --- | --- |
| AI = 一个无所不能的“电脑大脑” | AI是一大类技术的总称，各有各的用处，没有哪个AI什么都会 |
| 会下棋的AI和会聊天的AI是一回事 | 内部原理可能完全不同。2016年以4比1赢了李世石的AlphaGo，是专为下围棋训练的，不会聊天 |
| 大模型 = AI的全部 | 大模型只是AI最里圈的一个子类 |
| 机器学习是机器“自己想明白了” | 它从数据里学规律；预测有用，不等于像人一样理解 |
| 神经网络“像人脑一样思考” | 只是受神经元的粗略启发，做的是数字运算 |
| ChatGPT就是“那个大模型” | ChatGPT是产品，内核才是大模型（第17章） |

## 小结

- 这四个词是套娃关系，不是并列：大模型 ⊂ 深度学习 ⊂ 机器学习 ⊂ 人工智能。
- 人工智能是最大的总称，是“让机器做智力活”的目标，底下的技术各不相同。
- 机器学习不写死规则，让机器从数据里找规律；学到规律不等于像人一样理解。
- 深度学习用很多层的神经网络来学，是今天用得最广的机器学习方法。
- 大模型是深度学习里专攻语言的一类。你用的Claude、ChatGPT，是在大模型外面又包了一层的产品（第17章）。

下一章，我们钻进最里圈的小套娃，看看大模型“大”在哪、里面那些数不清的“旋钮”是什么，以及最该弄清楚的一个误会：它不是一个能查的数据库。

## 小测验

> 共6题，涵盖概念、误区、情景、操作四类。答案与解析在每题下方的引用块里——先自己想，再对照。

1. **[基础·概念题]** 下面哪句话最准确地描述了这四个词的关系？ <!-- quiz: q01 revision: 2 -->
   - A. 四个词并列，是四种互不相干的技术，用的时候挑一种
   - B. 大模型包含深度学习，深度学习包含机器学习，机器学习包含AI
   - C. 大模型属于深度学习，深度学习属于机器学习，机器学习属于AI
   - D. AI和机器学习是一回事，深度学习和大模型是它下面的两类
   > **答案C。** 这是一组“套娃”式的包含关系：大模型在最里面、最具体，AI在最外面、最宽泛。B的四个词顺序没错，但包含方向说反了，是大圈装着小圈。A把嵌套误当成并列。D把AI和机器学习画了等号，可AI还包括人写规则的老办法；它也把深度学习和大模型说成平级，其实大模型是深度学习里的一支。

2. **[基础·概念题]** “机器学习”和传统程序最根本的区别是什么？ <!-- quiz: q02 revision: 3 -->
   - A. 传统程序靠人写好规则，机器学习让机器从数据里自己找规律
   - B. 机器学习不需要人参与，程序写好以后会自己越用越聪明
   - C. 机器学习先把大量数据存下来，用的时候再去里面查找匹配
   - D. 传统程序只会照做，机器学习能像人一样真正理解问题含义
   > **答案A。** 这是整张图里最关键的一次转弯：从“人写规则”变成“给数据、让机器自己总结规律”。B不对：数据要人准备，训练方法要人设计，而且常见的模型训练完参数就固定了，不会在使用中自己变聪明（第2章）。C把“学规律”和“存数据、查数据”混为一谈（第2章会专门纠正这一点）。D说过头了：学到有用的规律，不等于证明它像人一样理解。

3. **[进阶·误区题]** “会下围棋赢世界冠军的AI，肯定也很会聊天、什么都会”——这个想法错在哪？ <!-- quiz: q03 revision: 3 -->
   - A. 下棋系统规模还不够大，换成更大的模型就什么都会了
   - B. 会下围棋说明它已有通用智力，只是还没人教它说话
   - C. 围棋AI其实不算AI，它只是一套人写死规则的程序
   - D. 两类系统可能用不同方法训练，围棋强不代表也会聊天
   > **答案D。** “AI”是个大总称。为赢围棋而训练的系统，和为生成语言而训练的模型，设计和能力可能完全不同；某些方法可以共用，但一项任务做得好，不证明另一项也做得好。A以为“够大就什么都会”，B把下棋本事当成了通用智力，这两种都是常见的过度推断。C也不对：顶尖的围棋程序正是用机器学习训练出来的，并非人写死的规则。

4. **[基础·误区题]** “我用的ChatGPT，就是那个‘大模型’本身”——这句话哪里不够准确？ <!-- quiz: q04 revision: 2 -->
   - A. 没问题，ChatGPT和GPT只是同一样东西的两种叫法
   - B. ChatGPT是产品，内核是大模型，外面包了一层产品功能
   - C. ChatGPT没用大模型，它靠人写好的大量问答规则运行
   - D. 大模型只是ChatGPT里的一个插件，遇到难题时才会调用
   > **答案B。** 你点开就聊的是产品（像“餐厅”），真正会接话的内核（像“厨师的手艺”）才是大模型。日常混着说问题不大，但心里要分清这两层（第17章专门讲模型、产品、API、Agent的区别）。A正是题目里的误解；C说反了，它的内核就是大模型；D把主次颠倒了，大模型是核心，不是偶尔调用的插件。

5. **[基础·情景题]** 朋友指着手机相册说：“它能自动认出哪些照片里有猫，这也是AI吗？它和我聊天用的AI是一个吗？”你该怎么回答最准确？ <!-- quiz: q05 revision: 2 -->
   - A. 都是AI，而且手机里认猫和聊天用的一定是同一个模型
   - B. 认猫不算AI，只是按颜色和形状去匹配的普通功能
   - C. 都算AI，但认猫多属计算机视觉，聊天靠的是语言模型
   - D. 只有会聊天的才算AI，认图功能只能算是图像处理
   > **答案C。** 两者都属于AI，只是任务不同：找出照片里的猫是计算机视觉任务，聊天用到语言模型。现在也有多模态模型把看图和语言结合起来，所以具体某个产品用了什么，要看它实际支持什么。A把“都是AI”推成了“一定是同一个模型”；B和D武断地把其中一类排除在AI之外。

6. **[基础·操作/观察题]** 环顾你自己一天会用到的“AI”：手机的人脸解锁、相册的物体识别、输入法的联想、地图的路线规划、垃圾短信拦截、你常用的聊天AI……挑出三四个，试着说出每一个**大致落在套娃图的哪一圈**，以及“它属于‘会聊天’那一支吗”。 <!-- quiz: q06 revision: 2 -->
   > **该观察到：** 这些功能中许多会用到AI，但不都依靠大语言模型。人脸解锁和物体识别常用计算机视觉；路线规划也可能用传统搜索算法；垃圾过滤、输入联想则可采用多种方法，包括语言模型。仅凭产品名称，不能确定内部实现。练习的重点是问清它做什么、用了哪类技术，而不是把“AI”等同于“什么都会”。
