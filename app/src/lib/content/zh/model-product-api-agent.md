打开聊天应用，你可能看到模型选择器，又听说同一家公司提供 API 和 Agent。这些词描述的是系统的不同部分。分清它们，才能知道自己在用什么、为什么付费，以及 AI 到底能做什么。

## 一、先上地图：四个层次

| 术语 | 描述什么 | 简单例子 |
| --- | --- | --- |
| **模型** | 处理输入、生成输出的系统 | 阅读一段文字，生成摘要 |
| **产品** | 给人使用的应用，包括界面、存储和工具 | 在聊天应用里上传文档 |
| **API** | 程序请求服务的约定接口 | 文档软件把文字发送给模型服务 |
| **Agent（智能体）** | 为目标选择步骤，通常会使用工具并检查结果的系统 | 查找文档、比较内容、整理有出处的报告 |

把它们理解为**四个观察角度，不是四个互斥的盒子，也不是必须依次搭建的四层楼**。产品可以包含 Agent，Agent 可以通过 API 调用模型；本地应用也可以直接运行模型，不经过云端 API。

## 二、第①层 模型：会思考的"内核"

模型提供理解语言、识别图像、生成文字等能力。支持哪些输入和输出，要看具体模型。能看图不等于能生成图片，能处理音频也不等于产品提供实时语音对话。

仅凭模型名称，不能判断有没有联网搜索、偏好记忆或文件编辑功能，这些还取决于外围系统。“大脑”只是比喻，不表示它像人一样理解和记忆。

## 三、第②层 产品：包给"人"用的那层

ChatGPT 是 OpenAI 的产品；Claude 和 Gemini 既用于指模型家族，也用于指各自公司的产品。需要区分时，可以说“Claude 应用”或“一个 Gemini 模型”。

产品可能在多个模型之间选择，保存聊天历史，检索文件，通过另一个服务生成图片，或者提供 Agent 模式。实际体验还取决于套餐、地区、组织设置和权限。**同一个模型放进两个产品里，使用体验可能不同。**

## 四、第③层 API：开给"程序"用的接口

API 像一张程序可以填写和读取的订单表：程序按约定提交请求，例如要总结的文字，再收到规定格式的结果。API 可以提供模型推理、搜索、文件访问等服务；API 本身不是模型。

使用基于 API 构建的产品，不要求你懂编程。另外，**聊天订阅不自动包含另行计费的开发者 API 用量**。有些工具可以用订阅账号登录，有些需要 API 密钥或单独余额。先确认具体工具采用哪条付费路径，不要把不同账户权益混为一谈。API 密钥可能授权访问和消费，应当像其他凭据一样保管。

## 五、第④层 Agent：会"自己动手"的那层

Agent 围绕结果推进工作：它可能先搜索，阅读结果，发现缺口，再搜索，最后整理交付物。本章关注的特征是**根据观察结果选择和调整步骤**。

调用一次搜索工具，不足以说明系统具备有意义的自主性；固定流程也能调用工具。反过来，只做调查并写报告、没有修改外部文件的系统，也可能是 Agent。“Agent”在实际产品里用法很宽，判断时要看行为和权限。

## 六、四层是怎么叠起来的

对于“比较这三份合同”，一种可能的路径是：

```text
你使用产品
  → Agent 决定查看哪些条款
  → 工具检索有权访问的片段
  → API 把片段交给模型
  → 模型生成比较结果
  → 产品显示结果和来源
```

这只是一种组合。工具、模型服务和文件存储可能属于不同公司。**运行在笔记本上的程序，仍可能把文档片段发给云端模型。** 判断隐私要追踪内容去了哪里，不能只看应用图标在哪里。

## 七、实用判断：我面对的是哪一层？

问三个具体问题：

1. **我打开的是什么？** 网站、手机应用、桌面工具属于产品。
2. **谁在处理内容，在哪里处理？** 找出模型或服务，确认本地还是远程；产品没有披露的细节就标为未知。
3. **它能决定并执行什么？** 区分建议方案、固定自动流程和会调整下一步的 Agent，查看它实际拥有的工具和权限。

## 八、常见误解，集中纠正

| 误解 | 纠正 |
| --- | --- |
| Claude 一定只指模型 | 也可能指产品，要看语境 |
| 买了订阅，所有 API 调用都包含在内 | 各服务的登录方式和计费安排不同 |
| Agent 一定是独立而且更强的模型 | Agent 行为来自围绕模型和工具构建的系统 |
| 调一次工具就代表自主工作 | 固定流程也能调用工具 |
| 桌面应用表示本地处理 | 模型或连接的工具仍可能在云端 |

## 小结

四个词分别帮你回答：**谁生成、你用什么、软件如何连接、工作怎样组织**。它们在真实系统里会重叠。下一章用这张地图，为实际任务选择产品。

## 小测验

1. **[基础·概念题]** 对这四个术语，哪种描述最准确？ <!-- quiz: q01 revision: 1 -->
   - A. 它们是四种互相竞争的模型
   - B. 每个产品都必须按同样顺序包含全部四层
   - C. 它们描述系统的不同部分，可以重叠
   - D. API 一定是 Agent
   > **答案：C。** 产品可以包含通过 API 调用模型的 Agent，也可以采用其他组合。

2. **[基础·概念题]** API 是什么？ <!-- quiz: q02 revision: 1 -->
   - A. 程序请求服务时使用的约定接口
   - B. 参数更多的模型
   - C. 付费聊天订阅
   - D. 屏幕识别功能
   > **答案：A。** 它连接程序和服务，服务既可以是模型，也可以是其他功能。

3. **[基础·误区题]** 助手联网搜索了一次。你能得出什么结论？ <!-- quiz: q03 revision: 1 -->
   - A. 它可以独立完成任何任务
   - B. 它至少有搜索能力，但这不足以证明它会自适应地循环推进任务
   - C. 它能修改你的文件
   - D. 它一定在本地运行
   > **答案：B。** 还要看它是否会选择、调整步骤，以及具有什么权限。

4. **[进阶·情景题]** 你买了聊天订阅，另一个工具要求 API 密钥。应该检查什么？ <!-- quiz: q04 revision: 1 -->
   - A. 图标是否一样
   - B. 模型名字是否更长
   - C. 该工具的认证和 API 用量是否包含在订阅中，还是另行计费
   - D. 能否把密钥公开粘贴
   > **答案：C。** 聊天订阅和开发者 API 余额不自动属于同一项权益。

5. **[基础·情景题]** 桌面助手使用云端模型读取文档。文档内容可能在哪里处理？ <!-- quiz: q05 revision: 1 -->
   - A. 只在桌面，因为应用安装在那里
   - B. 哪里都不处理，模型不用处理输入
   - C. 只在打印机里
   - D. 取决于应用发送了什么，可能在云端服务处理
   > **答案：D。** 安装位置与处理位置是两个问题。

6. **[基础·观察题]** 产品没有披露处理这次请求的具体模型。怎样描述最稳妥？ <!-- quiz: q06 revision: 1 -->
   - A. 猜一个可能的模型名
   - B. 说明产品和可见能力，把底层模型标为未知
   - C. 假设它没有模型
   - D. 假设它使用最贵的模型
   > **答案：B。** 有用的地图可以包含未知项，品牌名不能证明具体模型版本。
