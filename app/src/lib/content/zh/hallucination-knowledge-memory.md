它能写诗、能改代码、能把一篇长文总结得条理清楚，可你多半也碰到过两件让人泄气的事：一是它很认真地说错，引一篇根本不存在的论文，报一个查不到的“专家”，数字编得像模像样；二是它记不住你，昨天才告诉过它的事，今天新开一个对话，它完全不知道。

这两件事都出在它的工作方式上，不是它在“偷懒”。这一章讲三件事：为什么会说错（幻觉），说错了怎么查出来（核对），以及哪些东西它一直记得、哪些一转眼就没了（知识和记忆）。书里别的章节说“要核对”，指的都是这一章的办法。

## 一、幻觉：把不存在的东西，说得像真的一样

**幻觉**（hallucination）指模型把不存在的或错误的内容说得像真的一样。会错不稀奇，谁都会错；麻烦的是，错的内容往往和对的一样流畅、一样肯定，光看说法很难分出来。

为什么会这样？有两个原因。

一是生成的时候不查真假。模型做的事是根据前文接出合理的下文（第4章），手边没有一个“事实数据库”可以逐条对照。知识不够时，它可以说“我不确定”，有时也真会这么说；但它也可能顺着话头，接出一个读起来最顺的答案。一篇假论文能编得像真的，标题、作者、期刊样样齐全，正是因为它见过成千上万篇真论文长什么样。它不是在撒谎（撒谎要先知道真相），只是没把握的时候，照样把话接了下去。

二是训练和评测常常鼓励“猜”。2025年9月，OpenAI的研究者在论文《Why Language Models Hallucinate》和同期的介绍文章里指出：很多评测只看答对没答对，回答“我不知道”和答错一样是零分。这就像答错不扣分的选择题考试，猜一个总比空着强。模型照这种标准去优化，就容易学会“没把握也给个答案”。他们建议评测时答错要扣得比说“不确定”更重，让老实承认没把握不再吃亏。

那它表现出来的“把握”能不能参考？可以参考一点，但不能当证据。模型的把握和答对的可能性有一些关联：它明确说“不确定”的地方，往往确实更容易错，要当回事。反过来就不成立了：说得肯定、流畅，并不证明是对的。

## 二、怎么核对：一套照着做的办法

不是每句话都要查。头脑风暴、改改措辞、起个标题，看着合适就可以。但下面这些一旦错了代价大，要一条条核对：数字和金额、日期、人名和机构、引用和出处、链接、法律医疗财务方面的结论、“最近发生的事”，还有要拿去运行的代码和公式。

核对可以分四步：

1. 先让它少编。把可靠的资料贴进去，让它只根据这些资料回答，资料里没有就直说“资料里没有”；再明确告诉它“没把握就说不确定”。这一步能少出些错，但代替不了后面几步。
2. 让它把依据摆出来。要求每条关键说法都注明出自哪份资料的哪一句，或者给出能打开的链接。说不出依据、依据含糊的地方，就是你要重点查的地方。
3. 自己到源头去看。点开链接，确认页面存在，而且原文真是这么说的，别只看标题；引文逐字对照；数字回到原始表格或报告里去找；论文和书，拿标题去学术搜索或出版社网站查一查，有DOI编号的，到doi.org输进去看能不能打开。它给的“出处”本身也可能是编的。
4. 再找一个独立来源对一对。官方网站、原始文件、权威工具书都算；能算的用计算器或表格重算一遍，代码就实际跑起来、跑测试（第25章）。同一个AI换个问法再问一遍不算核对，编出来的内容也可能每次都一样。让另一个AI来挑错，可以帮你找出可疑的地方，但最后还是要回到源头去确认。

重要的结论，顺手记下来源和核对日期。下次再用，或者别人问起，你说得清它从哪来。第一步的思路是“把对的资料放到它面前，而不是赌它记得对”，这也是后面RAG（第20章）的基本思路。

## 三、知识和记忆：一张表分清“记得牢”和“转头忘”

它“知道”的东西其实分两种，性质完全不同。初学者最常见的错，就是把这两种当成一回事。

- **知识**（knowledge）：训练时学进参数里的常识和事实。不用你给材料它也答得上，你问“水的沸点”“唐朝在宋朝前还是后”，它直接就能回答。
- **上下文中的记忆**（memory in context）：这次请求的上下文里能用到的临时信息，也就是第3章那张“桌面”。你告诉它的名字或偏好，要留在桌面上、或者被重新放上来，它才用得到。关掉窗口也不等于删了聊天记录：产品可能把历史存着，你接着聊时再放一部分回来。

并排看：

| | 知识 | 上下文中的记忆 |
| --- | --- | --- |
| 存在哪 | 学进参数里（训练时学的） | 只在这次请求的上下文里 |
| 哪来的 | 海量训练文本 | 你这次对话放进去的，或产品替你放进去的 |
| 能保持多久 | 一直都在，但有截止日期（见下） | 没放进这次的上下文就用不上；历史存不存由产品决定 |
| 不给材料也能答吗 | 能 | 不能，全看这次桌面上有什么 |
| 典型例子 | “巴黎是法国首都” | “我刚说过我对花生过敏” |

知识有一个躲不开的限制，叫**知识截止**（knowledge cutoff）：训练数据有个最后日期，这之后才发生的事、才出的新版本、才出现的新名词，模型本身不知道。你非要问，它可能说不知道，也可能编一个。比如截至2026年10月，Anthropic给Claude Opus 5.5标的可靠知识截止是2026年6月，那之后的事它本身知道得很少。所以问“最近发生了什么”，别信它不查资料直接给的答案：要么让它联网查（第19章，查到的也要按上一节核对），要么把最新资料贴给它。

## 四、最该弄清楚的误会：它会像人一样一直记得你吗？

你和它聊久了，难免觉得它“认识”你了。但第3章说过：模型本体没有跨对话的记忆。新开一个对话，如果产品没有把历史、记忆或自定义指令带进来，模型不会知道你之前说过什么。同一个对话聊得太长，快到上下文上限时，产品可能做摘要、删掉一部分、只找出相关的片段，或者干脆拒绝，早先的细节就可能丢掉（第3章）。模型本体里，根本没有一个跨对话存东西的地方。

你可能马上会问：那产品里的“项目”和“记忆”功能是怎么回事？我明明见过它记住我的偏好、记住整个项目。

答案是：这些功能做在模型外面的产品层。截至2026年10月，Claude、ChatGPT等不少产品都有项目和记忆一类的功能，另外还有编程工具的项目说明文件（如CLAUDE.md，见第28章）、账号里的个性化设置、公司内部的知识库等。它们做的是同一件事：对话时把相关信息重新放回这次的上下文。说到底，还是“没有记忆的模型，加上每次重新放进去的上下文”。有的产品会从聊天里自动挑出要记的内容，而且可能默认开着；各家具体怎么记、记多久、默认开不开、能不能删，变得很快，以各产品的官方说明为准（怎么管理见第13章，隐私方面见第37章）。

| | 模型本体 | 产品层的“记忆” |
| --- | --- | --- |
| 是什么 | 那个按概率接话的内核 | 产品在模型外面加的一层功能 |
| 记不记得你 | 不会自己保存过去的对话，只看这次提供的信息 | 帮你把“该记的”存起来 |
| 怎么做到的 | — | 对话时，把这些信息重新放回这次的上下文 |
| “记得”的边界 | — | 只有产品决定放回桌面的那部分；没放回来的，它照样不知道 |

分清这两层，就能猜到这些功能会怎么表现。它能“记得”的，永远是产品替你放回上下文的那部分。有时它突然“忘了”你设过的偏好，多半是那条信息这次没被放回桌面；可能是产品的检索、设置或挑选上下文出了问题，也可能是故障，光看“忘了”还说不准是哪一种。

## 五、常见误解，集中纠正

| 误解 | 实际 |
| --- | --- |
| 它说得越流畅、越自信，就越可靠 | 流畅自信不是证据；它说“不确定”要当回事，说得很肯定时，要紧的事实也要核对 |
| 它从来不会承认自己不知道 | 它可以说“不确定”，明确允许它这么说往往有用；但不能指望它每次都发现自己没把握 |
| 它“说错”是偶尔走神，提醒一下就好 | 幻觉和生成方式本身、训练评测鼓励“猜”都有关；要靠给材料、要依据、到源头核对来防 |
| 同一个问题问几遍答案都一样，就说明是对的 | 编出来的内容也可能每次都一样；要找独立来源核对 |
| 它知道最新发生的事 | 知识有截止日期，之后的事它本身不知道，非要问可能会编；要让它联网，或者给它资料 |
| 有“记忆”功能，说明模型本体记住了我 | 是产品层把信息重新放回上下文，模型本体并不记得 |

## 小结

- 幻觉是把不存在或错误的东西说得像真的一样。原因一是生成时不查真假（第4章），二是训练和评测常常奖励“猜”，不奖励承认不确定。它说“不确定”要当回事，但说得流畅肯定从来不是证据。
- 核对的四步：给材料让它少编，让它摆出依据，自己到源头去看，再找独立来源对一对。数字、日期、人名、引用、链接、专业结论和最新的事，最需要查。
- 知识学进了参数，不给材料也能答，但有知识截止；上下文中的记忆只限于这次请求看得到的信息，聊天记录存不存由产品管。
- 模型本体没有跨对话记忆。项目、记忆功能、项目说明文件、账号偏好、企业知识库，都是产品层把信息重新放回上下文。
- 总之，它既没有“真相库”，也没有“长期记忆库”，只有参数里的知识（有截止）和这次桌面上的上下文。会说错、会忘，都是因为这一点。

第一部分到这里就读完了，你对模型“是什么、怎么运转”已经有了大致的感觉。下一部分开始讲怎么把它用好：从第一次认真对话，到怎么用提示词把“我想要什么”说清楚。

> 共6题，涵盖概念、误区、情景、操作四类。答案与解析在每题下方的引用块里——先自己想，再对照。

1. **[基础·概念题]** “幻觉（hallucination）”指的是？ <!-- quiz: q01 revision: 2 -->
   - A. 模型卡住不动或回答极慢，像陷入了混乱一样
   - B. 模型故意说假话误导用户，背后有明确的目的
   - C. 模型把不存在或错误的内容说得有模有样
   - D. 模型把你的对话内容泄露给了其他用户
   > **答案C。** 幻觉的要害是错的内容说得像真的，光看表达难以分辨。成因包括生成方式本身不核实真假，以及训练和评测常常鼓励“猜”。A是性能问题，D是隐私问题（第37章），都不是幻觉。B把它想成有意欺骗：模型没把握时接出了像样的错话，这和“明知真相还撒谎”不是一回事。

2. **[基础·概念题]** 下面哪一项，正确区分了“知识”和“记忆”？ <!-- quiz: q02 revision: 2 -->
   - A. 知识来自训练且有截止日期，记忆靠本次的上下文
   - B. 知识只在这次对话里有效，记忆则写进了模型参数
   - C. 两者都会随时间自动更新，问什么都能拿到最新的
   - D. 两者是一回事，只是同一个功能的两种不同叫法
   > **答案A。** 知识来自训练，长期都在，但有“知识截止”；上下文中的记忆依赖本次请求提供的信息，历史保存由产品管理，关闭窗口也不等于删除产品保存的历史。B把两者说反了。C不对，知识停在截止日期，记忆也不会自己更新。D忽略了两者来源和寿命的根本差别。产品可以保存并重新提供记忆，但这不等于模型参数学会了它。

3. **[进阶·误区题]** 它给你一段回答，引经据典、口吻笃定。有人说“讲得这么顺这么有把握，肯定可靠”。下面哪种看法最稳妥？ <!-- quiz: q03 revision: 3 -->
   - A. 没错，模型有把握就多半是对的，可以直接放心用
   - B. 正好相反，说得越笃定越说明在编，应该一律不信
   - C. 它都给出了引用来源，所以内容一定已经核实过
   - D. 笃定和正确只有一定关联，流畅自信不能当证据
   > **答案D。** 模型的把握程度和对错有一定关联，它说“不确定”值得重视；但说得笃定、流畅并不证明是对的，要紧的事实仍要核对。A把“有一定关联”推成了“可以放心用”。B走到了反面：笃定的回答很多时候是对的，一律不信同样不准确。C也危险，它连“来源”都可能是编的，所以要让它给依据，并且自己去核。

4. **[进阶·误区题]** “我用的产品有‘记忆’功能，能记住我的偏好，所以模型本体是记得我的。”哪里不对？ <!-- quiz: q04 revision: 2 -->
   - A. 说明这个模型比别的高级，天生就带有长期记忆
   - B. 是产品把保存的信息重新放进上下文，模型本体没变
   - C. 说明它把你的资料永久写进了参数，以后都知道
   - D. 完全正确，模型本体已经牢牢记住了你这个人
   > **答案B。** 关键是分清两层：模型本体没有跨对话记忆，“记忆”功能是产品层把存下的信息在对话时重新放回上下文（第3章那张桌子）。它能“记得”的，永远只是产品决定放回来的那部分；具体怎么存、能否删，以官方文档为准。A把产品功能当成了模型的天生能力。C以为改了参数，产品层记忆并不改动模型参数。D正是题目里的误解。

5. **[基础·情景题]** 你想让它帮你了解“上个月刚发布的某新产品”的细节，它却答得很有条理。最稳妥的做法是？ <!-- quiz: q05 revision: 3 -->
   - A. 把温度调高些再问一次，让它换个角度重新回答
   - B. 多问它几遍，只要每次答案都一致就说明是对的
   - C. 警惕知识截止，让它联网查或给它资料，再核对
   - D. 它答得这么详细具体，应该没问题，直接采信即可
   > **答案C。** “最近发生的事”正是知识截止的盲区，它可能编得像真的一样。要么让它联网查（第19章，查到也要复核），要么把官方资料贴给它，让它基于材料答，再自己核对关键点。A不解决问题，温度高只会更随意（第8章）。B不可靠，编出来的内容也可能每次都一样。D正中幻觉的陷阱：详细不等于真实。

6. **[基础·操作/观察题]** 故意问它一个**偏冷门又具体**的事实（如某本小众书的出版年、某条法规的具体条款），要求它“给出处”；再把一份你手上的可靠材料贴进去，让它“只根据这份材料”回答同一问题，并告诉它“材料里没有就说没有”。对比两次。 <!-- quiz: q06 revision: 2 -->
   > **该观察到：** 不给材料时，它可能编出像模像样、却查无实据的“出处”，也可能坦白说不确定；给了材料、要求它只基于材料答之后，回答通常更容易核对，也更少编造。这正是RAG（第20章）的核心思路：与其赌它记得对，不如把对的资料放到它面前。亲手对比一次，你会更清楚：说得像模像样，不等于有据可查。
