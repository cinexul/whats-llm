ここまでの九章では、モデルが「何で、どう動くのか」を見てきました。一語ずつ続きを書いていき（第4章）、生成するときに真偽を確かめないので、ときどき大まじめに作り話をする（第9章）。モデル本体には会話をまたぐ記憶もない（第3章）。

けれど、実際に入力欄を開いてキーボードに指を置くと、まず別の疑問が出てきます。これを何だと思って使えばいいのか。何でも知っている専門家なのか、検索エンジンなのか、仕事を手伝ってくれるアシスタントなのか。ここを間違えると、怖くて使えずにもったいないことをするか、信じすぎて間違いに気づかないかのどちらかになります。

この章では新しい仕組みは扱わず、どんな気持ちで付き合えばいいかだけを考えます。たとえは一つで十分です。AIを、とても博識だけれど、ときどき大まじめにデタラメを言う新人インターンだと思ってください。

## 一、いちばん近いのは誰か：「博識だがデタラメも言う新人インターン」

会社に新人インターンが来たと想像してください。こんな特徴があります。

| このインターン | モデルに当てはめると |
| --- | --- |
| 読んだ本の量がものすごく多い | 学習時にパラメータに取り込まれた膨大な知識（第2章） |
| 手が速く、疲れず、文句も言わない | 10版書けと言えば10版書くし、深夜3時でも動く |
| 話がうまく、いつも自信たっぷり | 「それらしく聞こえる」ことを目指すので、言い回しはいつも流暢で言い切り（第4章） |
| でも、ときどき大まじめに作り話をする | 知らないときに「分かりません」と言うとは限らず、それらしい偽の答えを作ってしまうことがある（第9章） |
| 昨日頼んだことを覚えていない | モデル本体には会話をまたぐ記憶がない。新しい会話で何を知っているかは、製品が今回何を持ち込んだかで決まる（第3章） |
| あなたが本当に何を求めているかは分からない | はっきり言わなかったことは推測するしかない（第11章で扱うのがこれ） |

このたとえは、「博識」と「デタラメも言う」の両方をセットで覚えてください。「博識」だけを覚えると、AIをうのみにして権威のように扱ってしまいます。「デタラメも言う」だけを覚えると、怖くなって何も任せられません。実際はどちらも本当です。AIはあなたより多くを知っていますが、言うことはあなたが確かめる必要があります。自分は**インターンを指導する人**だと考えるとちょうどいいでしょう。仕事は思い切って任せてかまいませんが、署名と結果の責任はあなたにあるので、最後のひと目は自分で見ます。

もちろん、AIは本物の人間ではなく、意図もなければ、さぼることも、わざとだますこともありません。「インターン」は加減をつかむためのたとえにすぎず、買いかぶりも見くびりもしないためのものです。

## 二、安心して外注できる仕事vsあなたが必ず引き受ける仕事

この加減がつかめたら、いちばん役に立つのは、どの仕事を任せてよく、どの仕事は自分で見ておくべきかを分けることです。分け方は第9章の続きです。答えがあなたの渡した材料の中にあり、間違えてもひと目で分かる仕事は安心して任せる。何もないところから事実を出させる仕事で、間違えると困る場合は、あなたが必ず引き受けます。

| | 安心して外注できる | あなたが必ず引き受ける |
| --- | --- | --- |
| 典型的なタスク | 推敲、言い換え、初稿の作成、アウトライン作り、ブレインストーミング、あなたが貼った資料の要約、翻訳、概念の説明 | 重要な数字、引用の出典、人名や日付、法律・医療・お金に関わる結論、外に公開する事実情報 |
| 理由 | 答えがあなたの渡したコンテキストの中にあるか、間違えてもひと目で気づき、すぐ直せる | 本物そっくりに作ってしまうことがあり（第9章）、間違えたときに困るのはあなた |
| あなたの役割 | 何がほしいかをはっきり伝え、上がってきたものを確認する | 自分でもう一度確かめ、確認できてから使う |

対照的な例を二つ挙げます。

```text
安心して外注:
   「この300字のお知らせを、保護者向けにもっと話し言葉で親しみやすく書き直して。」
   —— 材料は手元にあり、文体の仕事なので、間違えてもひと目で分かる。

必ず引き受ける:
   「ある税制の具体的な課税最低限はいくら?」
   —— 間違えられない事実の問題で、それらしく作ってしまうことがある(第9章)。
      出典を出させて自分で確かめるか、役所の公式サイトで直接調べる。
```

いちばん間違いやすいのは、安心して任せられそうに見えて、実は間違えられない事実がまぎれ込んでいる仕事です。たとえば「自社製品を紹介するメールを書いて」と頼むと、文章を書くのは得意分野ですが、ついでに仕様や価格、受賞歴まで書き込んだら、そこは確かめるべき事実になります。原稿を受け取ったら、まず具体的な数字、名前、日付、引用を抜き出して一つずつ確かめ（方法は第9章）、残りの文章は安心して使いましょう。

## 三、初回に何を期待し、何を期待しないか

期待をちょうどよく持っておけばがっかりしません。期待を間違えると、何でもできると思って痛い目を見るか、何もできないと思って使わずに終わるかのどちらかです。

期待してよいこと：

- ふつうの言葉が通じる。ふだんの話し言葉で頼めばよく、特別なコマンドや呪文を覚える必要はありません。
- すぐに使える初稿を出す。メール、アウトライン、文体の調整、概念の説明など、一度でそれなりの形にしてくれることがよくあります。
- 何度でも嫌がらず直す。気に入らなければもう一版、別の角度で、長く短く。何度頼んでも嫌な顔はしません。
- 渡した材料をもとに仕事をする。資料を貼って要約、対照、抽出をさせると、たいてい頼りになります（第12章で詳しく）。

期待しないほうがよいこと：

- 一言一句が本当であること。デタラメも言うので、流暢なほど気をつけましょう（第9章）。
- 昨日のことを覚えていること。新しい会話は基本的にゼロから始まります。製品のメモリ機能がオンでも、持ち込まれるのは保存された一部だけです（第3章）。
- 最新の情報を知っていること。知識にはカットオフがあり（第9章）、最近の出来事について、何も調べずに返ってきた答えはうのみにしないでください。
- あなたの心を読むこと。はっきり言わなかった要件は推測するしかありません（第11章で要件の伝え方を扱います）。

始めのうちは、楽をするためにAIを使い、結論まで任せるのは急がない、という使い方がおすすめです。仕事を0点から70点まで進めてもらう。下書き、整理、アイデア出しなら、速くて上手です。最後の30点、つまり事実の確認、何を残して何を捨てるかの判断、署名して責任を持つことは、自分に残しておきます。

## 四、「記憶があるかどうか」、初回からはっきりさせておく

初心者が最初にほぼ必ず持つ勘違いがあります。話し込むうちに、AIが自分を知っている、話したことを覚えている、となんとなく感じてしまうことです。

第9章で見たとおり、モデル本体には会話をまたぐ記憶がなく、AIが「覚えている」ように見えるのは、製品がコンテキストに戻してくれた部分です。2026年10月時点で、ClaudeやChatGPTなど多くの製品がプロジェクトやメモリのような機能を持っています。プロジェクトは資料や要件をまとめて何度も使える機能、メモリは好みや話した要点を保存しておく機能で、チャットから覚えることを自動で拾い、それが最初からオンになっている製品もあります。

初めての会話に当てはめると、ポイントは三つです。

- 覚えていると思い込まない。知っておいてほしい背景は、その会話の中ではっきり伝えます。
- 長く覚えておいてほしい好みは、製品のメモリやプロジェクト機能を使います（第13章で詳しく）。
- 覚えられたくない内容は、一時的なチャット（シークレットチャットと呼ぶ製品もあります）を使うか、メモリをオフにしてから話します。ときどき設定画面で何が保存されているかを見て、古いものや間違ったものは削除しましょう。呼び名、初期設定、削除の方法は製品ごとに違うので、公式の説明で確認してください。そもそもAIに送らないほうがいい内容については第37章を見てください。

「基本的に記憶はない」を出発点にすれば、急に知らない人のような顔をされても戸惑いません。同時に、メモリがオンの製品は、思っている以上に覚えているかもしれないことも知っておきましょう。

## 五、よくある誤解、まとめて訂正

| 誤解 | 実際 |
| --- | --- |
| AIは何でも知っているので権威として信じてよい | 博識だがデタラメも言う。あなたより多くを知っているが、言うことはあなたが確かめる |
| AIは何も当てにならないので仕事を任せられない | 推敲、下書き、整理、資料の要約は速くて上手。引き受けるべきは間違えられない事実の部分だけ |
| AIは検索エンジンのようなもので、出てくるのは調べた事実だ | その場で生成している（第2章）のであって、調べているわけではない。流暢でも正しいとは限らない（第4章・第9章） |
| 文章を書く仕事なら確認はまったく要らない | 文章にまぎれ込んだ数字、名前、出典は確かめる必要がある |
| たくさん話したから、AIは自分を「知っている」 | モデル本体には会話をまたぐ記憶がない。製品のメモリ機能が保存した情報をコンテキストに戻しているだけで、モデルが覚えているわけではない |
| 言わなくても望みを察してくれるはずだ | はっきり言わなかったことは推測するしかない。要件をはっきり伝えるのはあなたの仕事（第11章） |

## まとめ

- AIを、とても博識だけれど、ときどき大まじめにデタラメを言う新人インターンだと考える。「博識」と「デタラメも言う」はセットで覚える。あなたはインターンを指導する人で、仕事は任せてよいが、署名と結果の責任はあなたにある。
- 推敲、下書き、整理、資料の要約は安心して外注できる。重要な数字、出典、人名や日付、法律・医療・お金に関わる結論など、間違えられない事実はあなたが引き受ける。文章にまぎれ込んだ事実も同じ。
- 期待してよいのは、ふつうの言葉が通じる、すぐ初稿を出す、何度でも直す、材料をもとに仕事をすること。期待しないほうがよいのは、一言一句が本当、昨日を覚えている、最新情報を知っている、心を読んでくれること。
- まず楽をするために使い、70点まで進めてもらう。最後の30点、事実の確認と判断は自分に残す。
- 基本的に記憶はないと考える。長く覚えてほしい好みはメモリやプロジェクト機能で（第13章）。覚えられたくない内容は一時的なチャットを使うかメモリをオフにし、保存された記憶を定期的に見直して削除する。

次の章では、「心を読んでくれない」という困りごとを扱います。「何がほしいのか」をはっきり伝える方法、つまりプロンプトの組み立て方です。

1. **[基礎・概念問題]** 本章が勧める、モデルを何だと思って使うのが、いちばんさじ加減が安定しますか？ <!-- quiz: q01 revision: 2 -->
