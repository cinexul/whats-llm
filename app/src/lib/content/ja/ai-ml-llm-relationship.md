「AIは人間に取って代わるのか？」「AIはもう意識を持っているのでは？」「囲碁の世界チャンピオンにまで勝ったなら、何でもできるんじゃないか？」AIの話になると、話題は一気に大きく、つかみどころのない方向へ広がりがちです。

でも、人が口にする「AI」は、実はかなり違うものの寄せ集めです。将棋を指すのもAI、おしゃべりするのもAI、スマホのアルバムが「これは猫」と自動で見分けるのもAI、迷惑メールをはじくのもAI。これほど違うのに、なぜ同じ名前で呼ばれるのでしょうか。

この章でやることは一つだけです。「マトリョーシカ図」を使って、人工知能（AI）、機械学習（machine learning）、深層学習（deep learning）、大規模言語モデル（LLM）という、よく耳にするのに混同しやすい四つの言葉を整理します。この図が分かれば、身の回りのさまざまな「AI」を正しく位置づけられ、「将棋が指せる」と「おしゃべりできる」を同じものと取り違えなくなります。

## 一、まず一つだけはっきりさせる：これらは「マトリョーシカ」であって「横並び」ではない

この四つの言葉を、横に並んだ四つのもの、つまり四つのブランドのスマホから一つ選ぶような関係だと思う人は少なくありません。実際は、大きいものの中に小さいものが入る包含関係です。ロシアのマトリョーシカのように、大きい人形の中に小さい人形が収まっています。

```text
┌───────────────────────────────────────────────┐
│ 人工知能 AI（最も大きい円：機械に「知能のいる」ことをさせる）│
│   ┌───────────────────────────────────────┐   │
│   │ 機械学習 ML（機械にデータから自分で規則を見つけさせる）│   │
│   │   ┌───────────────────────────────┐   │   │
│   │   │ 深層学習 DL（「たくさんの層」で学ぶ）  │   │   │
│   │   │   ┌───────────────────────┐   │   │   │
│   │   │   │ 大規模言語モデル LLM（言語専門）│   │   │   │
│   │   │   └───────────────────────┘   │   │   │
│   │   └───────────────────────────────┘   │   │
│   └───────────────────────────────────────┘   │
└───────────────────────────────────────────────┘
```

内側へ行くほど、範囲は狭く、具体的になります。大規模言語モデルは深層学習の一種、深層学習は機械学習の一種、機械学習は人工知能の一種です。毎日おしゃべりに使っている大規模言語モデルは、いちばん内側の小さなマトリョーシカにすぎません。AIの世界のとても具体的な一角であって、AIのすべてではありません。

> **ポイント：** この図は一行で覚えられます。大規模言語モデル ⊂ 深層学習 ⊂ 機械学習 ⊂ 人工知能。

## 二、四つの円を、一層ずつ開いていく

まず表で全体をつかみ、それから一つずつ説明します。

| 層（大きい順） | 一言で言うと | 身近な例 | 一つ外の層との関係 |
| --- | --- | --- | --- |
| 人工知能（AI） | 本来は人間の頭脳が必要なことを機械にさせる | 将棋、画像認識、経路案内、迷惑メール対策 | 最も大きい総称。下のものはすべてAI |
| 機械学習（machine learning） | 人が規則を書かず、機械にデータから規則性を見つけさせる | 何万枚もの猫と犬の写真を見て、見分けられるようになる | AIの一つのやり方（唯一ではない） |
| 深層学習（deep learning） | 機械学習の一種で、層をたくさん重ねた計算ネットワークで学ぶ | 今日の画像・音声・翻訳の多くはこれに頼る | 機械学習の中で最も広く使われる分野 |
| 大規模言語モデル（LLM） | 深層学習の一種で、言語を専門に学ぶ巨大なモデル | Claude、ChatGPTのコア | 深層学習の中で「文字の続き当て」を主とする一類 |

### 第①層 人工知能（AI）：一つの「目標」であって、一つの「技術」ではない

人工知能は、四つの中で最も大きく、最も古い言葉です。指しているのは一つの目標で、本来は人間の知能が必要なことを機械にさせることです。顔を認識する、話を聞き取る、将棋を指す、車を運転する、買いたそうなものを勧める、といったことです。

AIは総称で、その下にはまったく異なる技術がたくさんあります。初期のAIの多くは、プログラマーが「盤面がこうなら、この手を打つ」と規則を一つずつ書き込んだもので、自分で学ぶ力はありませんでした。今日でも「AI」というラベルの下は千差万別で、将棋を指すもの、画像を見るもの、おしゃべりするもの、内部の仕組みはまるで違うことがあります。

言葉が大きすぎるので、「これはAIです」と聞いても、何ができて、どうやっているのかはまだ分かりません。続く三つの層は、「どの種類のAIか」をはっきりさせるためのものです。

### 第②層 機械学習（machine learning）：「人が規則を書く」から「機械が規則を見つける」へ

ここが図全体で最も大事な方向転換です。

従来のプログラムでは、人が規則を一つずつ書き、機械はそれに従って動きます。けれども、規則を書ききれないこともあります。「猫はどんな見た目か」を、コンピューターがすべての猫を見分けられるほど正確に言葉で説明できるでしょうか。耳がとがっている？ ひげがある？ ではキツネは？

**機械学習**は発想を変えました。規則を書く代わりに、データを与えるのです。「猫」「犬」と印を付けた写真を何万枚も見せ、違いを機械自身にまとめさせます。学び終えれば、見たことのない写真でも、たいてい言い当てられるようになります。

```text
従来のプログラム: 人が規則を考える  →  コードに書く  →  機械が従う
機械学習:         例をたくさん与える  →  機械が自分で規則を見つける  →  「判断する力」を学び取る
```

気をつけたいのは、機械が学ぶのはデータの中の規則性だということです。それを使って役に立つ予測ができますが、正解したからといって人間と同じように分かっているとは限りませんし、見たことのない状況では学んだ規則性が通用しないこともあります。AIがなぜ間違えるのかは、第9章で詳しく扱います。

### 第③層 深層学習（deep learning）：「たくさんの層」で学ぶ

機械学習には具体的な方法がたくさんあり、**深層学習**はこの十数年で最も広く使われている分野です。今日の画像・音声・翻訳・おしゃべりの多くは、これに頼っています。

「深層」とは、使う計算ネットワークが何層も重なっていることを指します。このネットワークを**ニューラルネットワーク（neural network）**と呼びます。データは第一層から入り、一層ずつ上へ伝わり、層ごとに少しずつ抽象的な情報が取り出されます。層が多いほど複雑な規則性を学べますが、層を増やせば良くなるというものでもありません。データや、ネットワークの作り方、学習のさせ方も同じくらい大事です。

ニューラルネットワークは、生物のニューロンをざっくり参考にして作られています。でも、その「ニューロン」がしているのはただの数値計算で、人間の脳をまねて作ったものではありません。名前だけでは、人間のような考えや感情があるかどうかは分かりません。

ここ数年で深層学習が急に強くなったのは、三つの条件が同時にそろったからです。データが増え（インターネット上の膨大な内容）、計算力が上がり（専用のチップ）、方法も成熟しました。

「深層学習」という言葉に単独で出会うことはあまりありません。製品の裏側に隠れているからです。あるAIが「ニューラルネットワークベース」「深層学習で作られた」と聞いたら、それはどんな技術を使っているかの話で、そのAIが具体的に何をするのかはまだ言っていない、と受け止めてください。

### 第④層 大規模言語モデル（LLM）：深層学習の中で「言語専門」の一類

いよいよいちばん内側の小さなマトリョーシカです。この本の主役でもあります。

**大規模言語モデル**（large language model、略してLLM）は、深層学習の中で言語（文字）を専門に扱う一類です。膨大なテキストから単語と単語のつながり方を学び、文章を書き、質問に答え、翻訳し、コードを書けるようになりました。Claude、ChatGPT、Geminiのコアは、どれもこの種類のモデルです。

言葉づかいについて一言。中国語の「大模型」や日本語の「大規模モデル」は、画像を扱う大規模な視覚モデルや、文字・画像・音声をまとめて扱うマルチモーダルモデルを指すこともあります。本書では、特に断りがない限り、大規模言語モデルの意味で使います。

地図上の位置について、気をつけたい点が二つあります。

- 大規模言語モデルは、深層学習の中でも言語を中心に扱う一派です。画像や音声にはそれぞれ別の手法がありますが、境目ははっきりしていません。今は多くのモデルがマルチモーダルで、文字も画像も音声も扱えます。会話が得意だからといって、ほかに何ができるかは分かりません。具体的なモデルと製品が何に対応しているかを確かめましょう（第18章）。
- どこが「大きい」のか、内部はどう動くのか、なぜ間違えるのかは、第2章から第9章で順に説明します。ここでは位置だけを押さえてください。いちばん内側の円で、AIのとても具体的な一部分です。

この位置に戻して見ると、大げさな言い回しにも振り回されにくくなります。「AIが目覚めた」「AIは何でもできる」は、いちばん外側の果てしない「AI」の話のように聞こえますが、実際に使っているのは、いちばん内側の、文字を扱う言語モデルです。強力ですが、その能力には限界があり、成り立ちもはっきりしています。

## 三、ではClaudeやChatGPTは、結局どの層なのか

ClaudeやChatGPTは大規模言語モデルそのものでは、と思うかもしれません。厳密に言えば、これらは大規模言語モデルを使って作った製品で、モデルそのものより少しだけ外側にあります。

たとえるなら、大規模言語モデルは腕のいい料理人で、ChatGPTやClaudeのアプリはレストランです。料理人を迎え、メニュー・テーブル・給仕をそろえて、初めて客が入って注文できます。開いてすぐおしゃべりできる画面は製品で、その裏で実際に言葉を続けているコアが大規模言語モデルです。

| あなたが言うこと | 実際は | マトリョーシカ図では |
| --- | --- | --- |
| 「ChatGPTを使っている」 | 一つの製品（人が使うチャット画面） | コアは大規模言語モデルで、外側に製品の層がある |
| 「ChatGPTのコアはGPT」 | GPTが大規模言語モデル | いちばん内側の小さなマトリョーシカ |
| 「Claude」 | モデルシリーズも、その製品もよく指す | 文脈しだい。料理人のことも、レストランのこともある |

モデル・製品・API・エージェントの区別は、第17章でまるごと一章を使って説明します。ここでは、毎日使うAIチャット製品は、大規模言語モデルの外側に人が使うための包みをもう一枚かぶせたもの、と分かれば十分です。

## 四、よくある誤解、まとめて訂正

| 誤解 | 実際 |
| --- | --- |
| AI = 何でもできる「コンピューターの頭脳」 | AIは多くの技術の総称で、それぞれ得意分野がある。何でもできるAIはない |
| 囲碁や将棋のAIとおしゃべりするAIは同じもの | 内部の仕組みはまったく違うことがある。2016年にイ・セドル九段に4勝1敗で勝ったAlphaGoは囲碁専用に学習したもので、会話はできない |
| 大規模言語モデル = AIのすべて | 大規模言語モデルは、AIのいちばん内側にある一分野にすぎない |
| 機械学習は機械が「自分で分かった」 | データから規則性を学ぶ。役に立つ予測ができても、人間と同じ理解とは限らない |
| ニューラルネットワークは「人間の脳のように考える」 | ニューロンから大まかな着想を得ただけで、行っているのは数値計算 |
| ChatGPTこそが「あの大規模言語モデル」だ | ChatGPTは製品で、コアが大規模言語モデル（第17章） |

## まとめ

- 四つの言葉はマトリョーシカの関係で、横並びではない。大規模言語モデル ⊂ 深層学習 ⊂ 機械学習 ⊂ 人工知能。
- 人工知能は最も大きい総称で、「機械に知的な作業をさせる」という目標。その下の技術は互いに大きく異なる。
- 機械学習は規則を書き込まず、機械にデータから規則性を見つけさせる。規則性を学べても、人間と同じ理解とは限らない。
- 深層学習は多層のニューラルネットワークで学ぶ方法で、今日最も広く使われている機械学習の手法。
- 大規模言語モデルは深層学習の中で言語を専門に扱う一類。使っているClaudeやChatGPTは、その外側にもう一層を包んだ製品（第17章）。

次章では、いちばん内側の小さなマトリョーシカの中に入り、大規模言語モデルはどこが「大きい」のか、中にある無数の「つまみ」とは何か、そしていちばん解いておきたい誤解、つまり調べものができるデータベースではないという話を見ていきます。

1. **[基礎・概念問題]** 次のうち、この四つの言葉の関係を最も正確に述べているのはどれ？ <!-- quiz: q01 revision: 2 -->
   - A. 四つは横並びで、互いに無関係な技術。使うときにどれか一つを選ぶ
   - B. 大規模言語モデルが深層学習を含み、深層学習が機械学習を、機械学習がAIを含む
   - C. 大規模言語モデルは深層学習に、深層学習は機械学習に、機械学習はAIに含まれる
   - D. AIと機械学習は同じもので、深層学習と大規模言語モデルはその下の二つの分類
   > **答えC。** これは「マトリョーシカ」型の包含関係です。大規模言語モデルが最も内側で最も具体的、AIが最も外側で最も広い。Bは並び順こそ合っていますが、包含の向きが逆です。大きい円が小さい円を含みます。Aは入れ子を横並びと取り違えています。DはAIと機械学習を同一視していますが、AIには人が規則を書く昔ながらの方法も含まれます。また深層学習と大規模言語モデルを同格に並べていますが、大規模言語モデルは深層学習の一分野です。

2. **[基礎・概念問題]** 「機械学習」と従来のプログラムの最も根本的な違いは？ <!-- quiz: q02 revision: 2 -->
   - A. 従来は人が規則を書き、機械学習では機械がデータから自分で規則性を見つける
   - B. 機械学習には人の関与が要らず、一度作れば使うほど勝手に賢くなっていく
   - C. 機械学習はまず大量のデータを保存し、使うときにその中から一致するものを探す
   - D. 従来のプログラムは指示どおり動くだけだが、機械学習は人間のように意味を理解する
   > **答えA。** これはこの図全体で最も肝心な方向転換です。「人が規則を書く」から「データを与え、機械に規則性をまとめさせる」へ。Bは誤りです。データは人が用意し、学習方法も人が設計します。よくあるモデルは学習後にパラメータが固定され、使っているうちに勝手に賢くなるわけではありません（第2章）。Cは「規則性を学ぶ」ことと「データを保存して検索する」ことを混同しています（第2章で詳しく正します）。Dは言い過ぎで、有用な規則性を学べても、人間のように理解している証明にはなりません。

3. **[応用・誤解問題]** 「囲碁で世界チャンピオンに勝つAIは、きっとおしゃべりも上手で、何でもできるに違いない」――この考えのどこが間違っている？ <!-- quiz: q03 revision: 2 -->
   - A. 囲碁のシステムはまだ規模が小さく、もっと大きくすれば何でもできるようになる
   - B. 囲碁に勝てるなら汎用的な知能はすでにあり、話し方を教わっていないだけだ
   - C. 囲碁のAIは実はAIではなく、人が規則を書き込んだだけのプログラムにすぎない
   - D. 二つは別の方法で学習していることがあり、囲碁が強くても会話が得意とは限らない
   > **答えD。** 「AI」は広い総称です。囲碁に勝つために学習したシステムと、言語を生成するために学習したモデルでは、設計も能力も大きく異なることがあります。手法の一部を共有することはあっても、ある課題での成功は別の課題での成功を証明しません。Aの「大きければ何でもできる」、Bの「囲碁の強さ＝汎用的な知能」は、どちらもよくある推論の飛躍です。Cも誤りで、トップクラスの囲碁プログラムはまさに機械学習で学習したもので、人が書き込んだ規則ではありません。

4. **[基礎・誤解問題]** 「私が使っているChatGPTは、あの『大規模言語モデル』そのものだ」――この一文のどこが正確でない？ <!-- quiz: q04 revision: 2 -->
   - A. 問題ない。ChatGPTとGPTは同じものを別の名前で呼んでいるだけだ
   - B. ChatGPTは製品で、コアが大規模言語モデル。外側に製品の機能が一層ある
   - C. ChatGPTは大規模言語モデルを使わず、人が書いた大量の問答規則で動いている
   - D. 大規模言語モデルはChatGPTのプラグインで、難しい質問のときだけ呼ばれる
   > **答えB。** 開いておしゃべりしているのは製品（「レストラン」のようなもの）で、実際に言葉を続けるコア（「料理人の腕前」のようなもの）が大規模言語モデルです。日常会話で混ぜて言っても大きな問題はありませんが、この二つの層は頭の中で区別しておきましょう（第17章でモデル・製品・API・エージェントの違いを扱います）。Aは設問の誤解そのものです。Cは逆で、コアはまさに大規模言語モデルです。Dは主従が逆転しています。大規模言語モデルは中心部分であって、ときどき呼ばれるプラグインではありません。

5. **[基礎・場面問題]** 友人がスマホのアルバムを指して言いました。「どの写真に猫が写っているか自動で見分けてくれるんだけど、これもAI? おしゃべりに使うAIと同じもの？」あなたはどう答えるのが最も正確？ <!-- quiz: q05 revision: 2 -->
   - A. どちらもAIで、スマホの猫認識とチャットは必ず同じモデルを使っている
   - B. 猫の認識はAIではなく、色や形で照合しているだけの普通の機能だ
   - C. どちらもAIだが、猫の認識は主にコンピュータービジョン、会話は言語モデル
   - D. おしゃべりできるものだけがAIで、画像認識はただの画像処理にすぎない
   > **答えC。** どちらもAIに属し、課題が異なります。写真から猫を見つけるのはコンピュータービジョンの課題で、会話には言語モデルを使います。画像と言語を組み合わせるマルチモーダルモデルもあるので、具体的な製品が何を使っているかは、実際の対応機能を確かめる必要があります。Aは「どちらもAI」から「必ず同じモデル」へ飛躍しています。BとDは、一方を根拠なくAIから外しています。

6. **[基礎・操作/観察問題]** 自分が一日に使う「AI」を見回してみましょう：スマホの顔認証ロック解除、アルバムの物体認識、入力予測、地図の経路案内、迷惑メールの遮断、よく使うチャットAI……。三つ四つ選び、それぞれが**マトリョーシカ図のどの円におおよそ収まるか**、そして「『おしゃべりする』一派に属するか」を言ってみてください。 <!-- quiz: q06 revision: 2 -->
   > **観察できるはず：** こうした機能の多くはAIを使いますが、すべてが大規模言語モデルを使うわけではありません。顔認証や物体認識ではコンピュータービジョンがよく使われ、経路案内では従来の探索アルゴリズムを使う場合もあります。迷惑メールの判定や入力予測には、言語モデルを含むさまざまな方法があります。製品名だけで内部の仕組みは決められません。「AIなら何でもできる」と考えず、何をするシステムで、どの技術を使っているかを確認するのが、この練習の目的です。
