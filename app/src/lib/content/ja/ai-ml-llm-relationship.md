「AIは人間に取って代わるのか？」「AIはもう意識を持っているんじゃないか？」「囲碁の世界チャンピオンにまで勝ったらしいぞ、じゃあ何でもできるんじゃないのか？」――「AI」という二文字が出てきた途端、話はいつも一気に大きく、そして妙な方向へ引っ張られていきます。

でも、気づいたことはありませんか。人々が口にする「AI」は、実はまったく別物の寄せ集めだということに。将棋を指すのもAI、おしゃべりするのもAI、スマホのアルバムで「これは猫だ」と自動で見分けるのもAI、迷惑メールがはじかれるのもAI。見た目はまるで似ても似つかないのに、なぜ同じ一つの名前を共有しているのでしょうか。

この章では難しい話はしません。やることはただ一つ――**「入れ子のマトリョーシカ図」を一枚お渡しする**ことです。人工知能(AI)、機械学習(machine learning)、深層学習(deep learning)、大規模言語モデル(LLM)という、最もよく耳にして、しかも最も混同されやすい四つの言葉を、一度ですっきり整理します。この図が分かれば、身の回りのどんな「AI」も正確に位置づけられるようになります――そして「将棋が指せる」ことと「おしゃべりできる」ことを、もう同じものと取り違えなくなります。これは、この先すべての章を理解するための土台です。

## 一、まず一つだけはっきりさせる：これらは「マトリョーシカ」であって「横並び」ではない

この四つの言葉を初めて聞くと、多くの人は**横に並んだ四つのもの**――四つのブランドのスマホから一つ選ぶようなもの――だと思ってしまいます。

**そうではありません。** これらは**大きいものの中に小さいものが入る、入れ子の包含関係**です――ロシアのマトリョーシカのように、大きい人形の中に小さい人形が収まっているのです。

```text
┌───────────────────────────────────────────────┐
│ 人工知能 AI（最も大きい円：機械に「知能のいる」ことをさせる）│
│   ┌───────────────────────────────────────┐   │
│   │ 機械学習 ML（機械にデータから自分で規則を見つけさせる）│   │
│   │   ┌───────────────────────────────┐   │   │
│   │   │ 深層学習 DL（「たくさんの層」で学ぶ）  │   │   │
│   │   │   ┌───────────────────────┐   │   │   │
│   │   │   │ 大規模言語モデル LLM（言語専門）│   │   │   │
│   │   │   └───────────────────────┘   │   │   │
│   │   └───────────────────────────────┘   │   │
│   └───────────────────────────────────────┘   │
└───────────────────────────────────────────────┘
```

この図の正しい読み方は、**内側へ行くほど範囲が狭く、より具体的になる**、というものです。大規模言語モデルは深層学習の一種、深層学習は機械学習の一種、機械学習は人工知能の一種です。逆に言えば、毎日おしゃべりに使っている大規模言語モデルは、いちばん内側の最も小さいマトリョーシカにすぎません――AIという世界全体の中の、**とても具体的な小さな一角**であって、決して「AIのすべて」ではないのです。

> **ポイント：** 一言だけ覚えれば十分です――**大規模言語モデル ⊂ 深層学習 ⊂ 機械学習 ⊂ 人工知能**。続く三つの節では、外から内へ、一層ずつ各円をはっきりさせていきます。何であり、なぜ必要で、人々はどこで誤解しがちなのか。

## 二、四つの円を、一層ずつ開いていく

まず一枚の対照表で全体感をつかんでから、一つずつ説明します。

| 層（大きい順） | 一言で言うと | 身近な例 | 一つ外の層との関係 |
| --- | --- | --- | --- |
| 人工知能(AI) | 機械に「本来は人間の頭脳が必要な」ことをさせる | 将棋、画像認識、経路案内、迷惑メール対策 | 最も大きい総称。下のものはすべてAI |
| 機械学習(machine learning) | 人が規則を書かず、機械に**データから自分で規則を見つけさせる** | 何万枚もの猫犬の写真を見て、自分で猫と犬を見分けられるようになる | AIの一つの**やり方**（唯一のやり方ではない） |
| 深層学習(deep learning) | 機械学習の一種で、**たくさんの層**の計算ネットワークで学ぶ | 今日の画像・音声・翻訳の多くはこれに頼る | 機械学習の中で**特に強い**一派 |
| 大規模言語モデル(LLM) | 深層学習の一種で、**言語専門**の超巨大モデル | Claude、ChatGPTのコア | 深層学習の中で**「文字の続き当て」を主とする**一類 |

### 第①層 人工知能(AI)：一つの「目標」であって、一つの「技術」ではない

**人工知能**は、この四つの中で最も大きく、最も古い言葉です。指しているのは一つの**目標**です――機械に「本来は人間の知能が必要な」ことをさせる。顔を認識する、話を聞き取る、将棋を指す、車を運転する、あなたが買いたそうなものを勧める。

肝心なのは、AIは**総称**であり、その下にはまったく**異なる**多種多様な技術が詰め込まれている、という点です。

- 初期のAIの多くは、プログラマーが**規則を一つひとつ書き込んだ**ものでした――「盤面がこうなら、この手を打つ」。この手のAIには「自分で学ぶ」能力など一切なく、すべて人があらかじめ考えておいたものに頼っていました。
- 今日でも、「AI」というラベルの下は相変わらず千差万別です――将棋を指すもの、画像を見るもの、おしゃべりするもの。**内部の原理はまるで違いうる**のに、ただ「機械を賢くする」という大きな目標にひとくくりにされているだけです。

> **なぜこの言葉が必要なのか？** 「機械に知的労働を代わらせる」という話をするときの便利な「大きな旗」になるからです。でも、まさに大きすぎるがゆえに、**「AI」はほとんど何も正確には言い表しません**――「これはAIです」と聞いても、それが結局何ができて、どうやっているのか、まだ分からないのです。だからこそ、続く三層が「どの種類のAIなのか」を正確に位置づけるためにあります。

### 第②層 機械学習(machine learning)：「人が規則を書く」から「機械が規則を見つける」へ

ここはこの図全体で**最も肝心な方向転換**です。必ず理解してください。

従来のプログラムはこうでした――人が規則を**一つひとつはっきり書き**、機械はそれに従って実行する。しかし、規則をどうしても書ききれないことがあります――「猫はどんな見た目か」を、コンピューターが一匹一匹の猫を認識できるほど正確に、文字で説明できますか？ 耳がとがっている？ ひげがある？ ではキツネは？

**機械学習**は発想を変えました――**規則を書くのをやめ、代わりにデータを与える**のです。「猫」「犬」と印を付けた写真を何万枚も機械に見せ、「猫と犬は結局どこが違うのか」を**自分で**まとめさせます。学び終えれば、見たことのない新しい写真を渡しても、だいたい言い当てられるようになります。

```text
従来のプログラム: 人が規則を考える  →  コードに書く  →  機械が従う
機械学習:         例をたくさん与える  →  機械が自分で規則を見つける  →  「判断する力」を学び取る
```

> **よくある誤解：** 「機械学習なら、機械が人間と同じように理解しているはずだ」。機械学習はデータからパターンや表現を学び、それが有用な予測や推論を支えます。ただし、正解すること自体は人間と同じ理解の証明にはならず、学んだパターンが未知の状況で通用しない場合もあります。データの質、学習方法、課題などが誤りに影響するため、AIのあらゆる失敗を一つの理由で説明することはできません（第9章）。

### 第③層 深層学習(deep learning)：「たくさんの層」で学ぶ

機械学習には具体的な方法がたくさんありますが、**深層学習**はこの十数年で**広く使われている**一分野で、今日の画像・音声・翻訳・おしゃべりは、ほとんどがこれに頼っています。

その名前にある「深」という字が指すのは、使われる「計算ネットワーク」――**ニューラルネットワーク(neural network)**――が**何層も何層も**重ねられていることです。データは第一層から入り、一層ずつ上へ伝わり、各層がそこから少しずつ抽象的な情報を取り出します。多層構造は複雑なパターンの学習に役立ちます。ただし、層を増やすだけで性能が上がるとは限りません。データ、ネットワークの設計、学習方法も重要です。

- **ニューラルネットワーク（neural network）**の設計は、生物のニューロンから大まかな着想を得ています。ただし、人工のユニットが行うのは数値計算であり、人間の脳を精密に再現したものではありません。名前だけで、人間のような思考や感情があるかどうかは判断できません。
- ここ数年で深層学習が急に強くなったのは、三つのものが同時にそろったからです――**データが増えた**（インターネット上の膨大な内容）、**計算力が強くなった**（専用のチップ）、**方法が成熟した**。

> **実際にどう出くわすか：** 「深層学習」という言葉に単独で出くわすことは、ほとんどありません――製品の裏側に隠れているからです。でも誰かが、あるAIを「ニューラルネットワークベースだ」「深層学習で作られている」と言ったら、心の中ではこう理解してください――これは**どの技術の筋を使っているか**を言っているのであって、機械学習という大きな円の中の一派にすぎず、**そのAIが具体的に何をするものかは、まだ言っていない**のだ、と。

### 第④層 大規模言語モデル(LLM)：深層学習の中で「言語専門」の一類

ついに、いちばん内側の小さなマトリョーシカに来ました――この本の主役です。

**大規模言語モデル（large language model、略してLLM）**は、深層学習の一種で、**言語（文字）を扱うことに特化**しています。膨大なテキストから「単語と単語がどうつながるか」を学び取り、文章を書き、質問に答え、翻訳し、コードを書けるようになりました。Claude、ChatGPT、Geminiのコアは、すべてこの類のモデルです。

言葉づかいについて一言。中国語の「大模型」や日本語の「大規模モデル」は、画像を扱う大規模な視覚モデルや、文字・画像・音声をまとめて扱うマルチモーダルモデルを指すこともあります。本書では、特に断りがない限り、大規模言語モデルの意味で使います。

その位置づけに注意してください。

- 大規模言語モデルは、深層学習の中でも**言語を中心に扱う分野**です。コンピュータービジョンは画像を扱い、音声を扱う手法もありますが、これらの分類は重なることがあります。現代の多くのモデルは、文字と画像・音声などを組み合わせる**マルチモーダル**な能力を持ちます。会話が得意というだけでは、ほかに何ができるかは分かりません。具体的なモデルと製品の対応機能を確認しましょう（第18章）。
- 「大」とは何が大きいのか、その内部は結局どう動くのか、なぜ間違えるのか――これらは**第2章から第9章**まで、一つの部分まるまる使って展開する内容です。ここでは、**地図上での位置**だけを押さえてください――**いちばん内側の円にあり、AIのとても小さく、とても具体的な部分集合だ**、と。

> **ポイント：** 大規模言語モデルをその位置に戻して見れば、多くの誇張された言い回しに即座に「免疫」がつきます――「AIが目覚めた」「AIは何でもできる」。これらは、いちばん外側の果てしない「AI」のことを言っているように聞こえますが、実際に使っているのは、いちばん内側の**「文字の続きを当てる言語モデル」**にすぎません。強いけれど、その能力には境界があり、由来があるのです。

## 三、ではClaudeやChatGPTは、結局どの層なのか

ここが最も引っかかりやすいところなので、独立してはっきりさせます。

こう聞きたくなるかもしれません。今の話のとおりなら、ClaudeやChatGPTは「大規模言語モデル」なんでしょう？――**厳密に言えば、これらは「大規模言語モデルの製品化」であり、純粋な大規模言語モデルより、もう少しだけ外側にあります。**

たとえるなら、大規模言語モデルは**とても腕のいい料理人**（料理を作る「腕前」）のようなもので、ChatGPTやClaudeのアプリは**一軒のレストラン**です――料理人を招き入れ、メニュー・テーブル・給仕を整えて、初めてあなたは「入って注文する」ことができます。日常的に開いておしゃべりするチャット画面は**製品**であり、その裏で本当に「言葉を続ける」コアこそが**大規模言語モデル**です。

| あなたが言うこと | 実際は | マトリョーシカ図では |
| --- | --- | --- |
| 「ChatGPTを使っている」 | 一つの**製品**（人が使うチャット画面） | コアは大規模言語モデル、外側に「製品」の層が一枚 |
| 「ChatGPTのコアはGPT」 | GPTこそがその**大規模言語モデル** | いちばん内側の小さなマトリョーシカ |
| 「Claude」 | モデルシリーズも指すし、その製品もよく指す | 文脈による。コアを指すことも、その「レストラン」を指すことも |

モデル・製品・API・エージェントというこれらの層をどう区別するかは、**第17章**でまるまる一章使って徹底的に説明します。ここでは、こう覚えておけば十分です――**毎日使う「AIチャット製品」は、いちばん内側の大規模言語モデルの外側に、もう一枚「人が使うための包み」をかぶせたもの**だ、と。相変わらず、AIという大きな地図の小さな一角に、しっかり収まっているのです。

## 四、よくある誤解、まとめて訂正

| 誤解 | 実際 |
| --- | --- |
| AI = 何でもできる「コンピューターの大脳」 | AIは一大類の技術の総称で、その下はそれぞれが一分野を受け持つ**専用**の能力ばかり。「何でもできる」AIなど存在しない |
| 将棋を指すAIとおしゃべりするAIは同じもの | 内部の原理は**まったく異なりうる**。ただどちらも「AI」と呼ばれているだけ。一方は将棋の読みが得意、一方は言語の処理が得意。一つの能力があっても、別の能力があるとは限らない |
| 大規模言語モデル = AIのすべて | 大規模言語モデルはAIのいちばん内側の**小さな部分集合の一つ**（深層学習の中で言語に特化した一派）にすぎない |
| 機械学習は機械が「自分で分かった」 | **データからパターンを学ぶ**。有用な予測ができることだけでは、人間と同じ理解の証明にはならない |
| ニューラルネットワークは「人間の脳のように考える」 | 設計はニューロンから**大まかな着想**を得ているが、人工のユニットは数値計算を行い、脳の精密な再現ではない |
| ChatGPTこそが「あの大規模言語モデル」だ | ChatGPTは**製品**で、コアこそが大規模言語モデル(GPT)。間に「人が使うための包み」が一層ある（第17章） |

## まとめ

- この四つの言葉は**マトリョーシカの関係**であって、横並びではない――**大規模言語モデル ⊂ 深層学習 ⊂ 機械学習 ⊂ 人工知能**、内から外へ、どんどん広くなる。
- **人工知能(AI)** は最も大きい総称――「機械に知的なことをさせる」という目標で、その下にはまったく**異なる**さまざまな技術が詰まっている。
- **機械学習** はAIの一つのやり方：規則を書き込まず、**機械にデータから自分で規則を見つけさせる**（ただし、パターンを学べること自体は、人間と同じ理解の証明にはならない）。
- **深層学習** は機械学習の中で広く使われる分野で、**多層のニューラルネットワーク**で学ぶ。人工のユニットは数値計算を行い、設計はニューロンから大まかな着想を得ている。
- **大規模言語モデル(LLM)** は深層学習の中で**言語に特化**した一類――使っているAIチャット製品のコアはこれだが、AI世界の**とても小さな一角**にすぎない。
- 日常的に使うClaudeやChatGPTは大規模言語モデルの**製品化**で、裸のモデルよりもう一層外を包んだもの（第17章で詳しく）。

次章では、いちばん内側の小さなマトリョーシカに入り込み、**大規模言語モデルが結局どこが「大きい」のか、その内部の「何十億ものつまみ」とは何の意味なのか**、そして最も破るべき誤解――**調べられるデータベースではない**――を見ていきます。

2. **[基礎・概念問題]** 「機械学習」と従来のプログラムの最も根本的な違いは？ <!-- quiz: q02 revision: 2 -->

   - B. 機械学習には人の関与が要らず、一度作れば使うほど勝手に賢くなっていく
   - C. 機械学習はまず大量のデータを保存し、使うときにその中から一致するものを探す
   - D. 従来のプログラムは指示どおり動くだけだが、機械学習は人間のように意味を理解する
   > **答えA。** これはこの図全体で最も肝心な方向転換です。「人が規則を書く」から「データを与え、機械に規則性をまとめさせる」へ。Bは誤りです。データは人が用意し、学習方法も人が設計します。よくあるモデルは学習後にパラメータが固定され、使っているうちに勝手に賢くなるわけではありません（第2章）。Cは「規則性を学ぶ」ことと「データを保存して検索する」ことを混同しています（第2章で詳しく正します）。Dは言い過ぎで、有用な規則性を学べても、人間のように理解している証明にはなりません。

3. **[応用・誤解問題]** 「囲碁で世界チャンピオンに勝つAIは、きっとおしゃべりも上手で、何でもできるに違いない」――この考えのどこが間違っている？ <!-- quiz: q03 revision: 2 -->
   - A. 囲碁のシステムはまだ規模が小さく、もっと大きくすれば何でもできるようになる
   - B. 囲碁に勝てるなら汎用的な知能はすでにあり、話し方を教わっていないだけだ
   - C. 囲碁のAIは実はAIではなく、人が規則を書き込んだだけのプログラムにすぎない
   - D. 二つは別の方法で学習していることがあり、囲碁が強くても会話が得意とは限らない
   > **答えD。** 「AI」は広い総称です。囲碁に勝つために学習したシステムと、言語を生成するために学習したモデルでは、設計も能力も大きく異なることがあります。手法の一部を共有することはあっても、ある課題での成功は別の課題での成功を証明しません。Aの「大きければ何でもできる」、Bの「囲碁の強さ＝汎用的な知能」は、どちらもよくある推論の飛躍です。Cも誤りで、トップクラスの囲碁プログラムはまさに機械学習で学習したもので、人が書き込んだ規則ではありません。

4. **[基礎・誤解問題]** 「私が使っているChatGPTは、あの『大規模言語モデル』そのものだ」――この一文のどこが正確でない？ <!-- quiz: q04 revision: 2 -->
   - A. 問題ない。ChatGPTとGPTは同じものを別の名前で呼んでいるだけだ
   - B. ChatGPTは製品で、コアが大規模言語モデル。外側に製品の機能が一層ある
   - C. ChatGPTは大規模言語モデルを使わず、人が書いた大量の問答規則で動いている
   - D. 大規模言語モデルはChatGPTのプラグインで、難しい質問のときだけ呼ばれる
   > **答えB。** 開いておしゃべりしているのは製品（「レストラン」のようなもの）で、実際に言葉を続けるコア（「料理人の腕前」のようなもの）が大規模言語モデルです。日常会話で混ぜて言っても大きな問題はありませんが、この二つの層は頭の中で区別しておきましょう（第17章でモデル・製品・API・エージェントの違いを扱います）。Aは設問の誤解そのものです。Cは逆で、コアはまさに大規模言語モデルです。Dは主従が逆転しています。大規模言語モデルは中心部分であって、ときどき呼ばれるプラグインではありません。

5. **[基礎・場面問題]** 友人がスマホのアルバムを指して言いました。「どの写真に猫が写っているか自動で見分けてくれるんだけど、これもAI? おしゃべりに使うAIと同じもの？」あなたはどう答えるのが最も正確？ <!-- quiz: q05 revision: 2 -->
   - A. どちらもAIで、スマホの猫認識とチャットは必ず同じモデルを使っている
   - B. 猫の認識はAIではなく、色や形で照合しているだけの普通の機能だ
   - C. どちらもAIだが、猫の認識は主にコンピュータービジョン、会話は言語モデル
   - D. おしゃべりできるものだけがAIで、画像認識はただの画像処理にすぎない
   > **答えC。** どちらもAIに属し、課題が異なります。写真から猫を見つけるのはコンピュータービジョンの課題で、会話には言語モデルを使います。画像と言語を組み合わせるマルチモーダルモデルもあるので、具体的な製品が何を使っているかは、実際の対応機能を確かめる必要があります。Aは「どちらもAI」から「必ず同じモデル」へ飛躍しています。BとDは、一方を根拠なくAIから外しています。

6. **[基礎・操作/観察問題]** 自分が一日に使う「AI」を見回してみましょう：スマホの顔認証ロック解除、アルバムの物体認識、入力予測、地図の経路案内、迷惑メールの遮断、よく使うチャットAI……。三つ四つ選び、それぞれが**マトリョーシカ図のどの円におおよそ収まるか**、そして「『おしゃべりする』一派に属するか」を言ってみてください。 <!-- quiz: q06 revision: 2 -->
   > **観察できるはず：** こうした機能の多くはAIを使いますが、すべてが大規模言語モデルを使うわけではありません。顔認証や物体認識ではコンピュータービジョンがよく使われ、経路案内では従来の探索アルゴリズムを使う場合もあります。迷惑メールの判定や入力予測には、言語モデルを含むさまざまな方法があります。製品名だけで内部の仕組みは決められません。「AIなら何でもできる」と考えず、何をするシステムで、どの技術を使っているかを確認するのが、この練習の目的です。
