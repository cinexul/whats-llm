チャットアプリを開くとモデル選択があり、同じ会社がAPIやエージェントも提供していると聞く。これらの言葉は、システムの異なる部分を表しています。区別できると、何を使い、何に支払い、AIに何ができるのかを判断しやすくなります。

## 一、まず地図：四つの層

| 用語 | 表すもの | 簡単な例 |
| --- | --- | --- |
| **モデル** | 入力を処理して出力を生成する仕組み | 文章を読み、要約を作る |
| **製品** | 人が使うアプリ。画面、保存機能、ツールなどを含む | チャットアプリで文書をアップロードする |
| **API** | ソフトウェアがサービスを要求するための決まった窓口 | 文書アプリがモデルサービスに文章を送る |
| **エージェント** | 目標に向けて手順を選び、多くの場合ツールを使って結果を確かめる仕組み | 文書を探し、比較して出典付きの報告書を作る |

これは**四つの見方**です。互いに排他的な分類でも、必ず順番に積む四階建てでもありません。製品がエージェントを含み、そのエージェントがAPI経由でモデルを呼ぶことがあります。ローカルアプリがクラウドAPIを使わずモデルを動かす構成もあります。

## 二、第①層 モデル：考える「コア」

モデルは言語の理解、画像の読み取り、文章生成などの能力を担います。対応する入力と出力は、個々のモデルによって異なります。画像を読めても画像を生成できるとは限らず、音声を処理できても製品がリアルタイム会話を提供するとは限りません。

モデル名だけでは、ウェブ検索、好みの保存、ファイル編集が使えるかは分かりません。周囲の仕組みにも依存します。「頭脳」は比喩であり、人と同じように理解や記憶をするという意味ではありません。

## 三、第②層 製品：「人」が使うために包んだ層

ChatGPTはOpenAIの製品です。ClaudeとGeminiは、モデル群と、それぞれの会社の製品の両方を指す名前です。区別が必要なら「Claudeのアプリ」「Geminiのモデル」と言い分けましょう。

製品は、複数モデルの選択、会話履歴の保存、ファイル検索、別サービスによる画像生成、エージェントモードなどを組み合わせます。プラン、地域、組織設定、権限も使い勝手に影響します。**同じモデルでも、組み込まれた製品が違えば実際の体験は変わります。**

## 四、第③層API：「プログラム」が使うための窓口

APIは、ソフトウェアが記入して読み取れる注文票のようなものです。プログラムは、要約したい文章などを決められた形式で送り、形式の決まった応答を受け取ります。APIが提供するのはモデルの推論だけでなく、検索やファイル操作などの場合もあります。API自体がモデルなのではありません。

APIを使って作られた製品を利用するだけなら、プログラミングの知識は不要です。また、**チャットの有料プランに、別途課金される開発者向けAPIの利用が自動的に含まれるわけではありません**。サブスクリプションのアカウントでログインするツールも、APIキーや別の残高が必要なツールもあります。実際に使うツールの支払い経路を確認しましょう。APIキーはアクセスや支払いを許可することがあるため、認証情報として管理します。

## 五、第④層 エージェント：「自分で手を動かす」層

エージェントは成果に向かって作業を進めます。検索結果を読み、足りない点に気づいて再検索し、成果物をまとめる、といった流れです。本章で重視する特徴は、**観察した結果に応じて手順を選び、調整すること**です。

一度ウェブ検索しただけでは、有意な自律性があるとは言えません。固定された処理手順でもツールを呼べます。一方、外部ファイルを変更せず、調査と報告だけを行うエージェントもあります。「エージェント」という呼び名は広く使われるため、実際の動作と権限を見て判断しましょう。

## 六、四層はどう重なるのか

「この三つの契約書を比較して」という依頼なら、例えば次の構成が考えられます。

```text
利用者が製品を使う
  → エージェントが確認すべき条項を選ぶ
  → ツールが閲覧権限のある箇所を取り出す
  → API 経由でその箇所をモデルに渡す
  → モデルが比較結果を生成する
  → 製品が結果と出典を表示する
```

これは構成例の一つです。ツール、モデルサービス、ファイル保存先が別々の会社に属する場合もあります。**ノートパソコン上のプログラムでも、文書の抜粋をクラウドモデルに送ることがあります。** プライバシーを考えるときは、アプリの置き場所ではなく、内容の送り先を追います。

## 七、実用的な見分け方：今向き合っているのはどの層？

三つの具体的な問いを使います。

1. **何を開いているか。** ウェブサイト、スマホアプリ、デスクトップツールは製品です。
2. **何が、どこで内容を処理するか。** モデルやサービスと、ローカルかリモートかを確認します。公開されていない詳細は不明とします。
3. **何を判断し、実行できるか。** 提案だけなのか、固定の自動処理なのか、次の手順を調整するエージェントなのかを区別し、実際のツールと権限を確認します。

## 八、よくある誤解、まとめて訂正

| 誤解 | 訂正 |
| --- | --- |
| Claudeは必ずモデルだけを指す | 製品を指すこともあり、文脈で決まる |
| 有料プランならAPI呼び出しもすべて含まれる | 認証と課金の仕組みはサービスごとに異なる |
| エージェントは必ず別の強力なモデルだ | モデルやツールを組み合わせた仕組みがエージェントの動作を作る |
| ツールを呼べば自律的だ | 固定の処理手順でもツールは呼べる |
| デスクトップアプリなら処理もローカルだ | モデルや接続先のツールはクラウドにある場合がある |

## まとめ

四つの言葉で、**何が生成するか、何を使うか、ソフトウェアをどう接続するか、仕事をどう進めるか**を整理できます。実際のシステムでは重なり合います。次章では、この地図を使って自分のタスクに合う製品を選びます。

## 小テスト

1. **[基礎・概念問題]** 四つの用語の説明として最も適切なのは？ <!-- quiz: q01 revision: 1 -->
   - A. 互いに競合する四種類のモデルである
   - B. 全製品が同じ順序で四層すべてを持つ必要がある
   - C. システムの異なる部分を表し、重なり合うことがある
   - D. APIは必ずエージェントである
   > **答え：C。** 製品が、API経由でモデルを呼ぶエージェントを含む場合も、別の構成の場合もあります。

2. **[基礎・概念問題]** APIとは？ <!-- quiz: q02 revision: 1 -->
   - A. ソフトウェアがサービスを要求するための決まった窓口
   - B. パラメータの多いモデル
   - C. チャットの有料プラン
   - D. 画面読み取り機能
   > **答え：A。** プログラムとサービスを接続します。サービスはモデル以外の機能でも構いません。

3. **[基礎・誤解問題]** アシスタントがウェブを一度検索しました。何が分かりますか？ <!-- quiz: q03 revision: 1 -->
   - A. どんな仕事でも独力で完了できる
   - B. 少なくとも検索機能があるが、結果に応じて手順を調整するとはまだ言えない
   - C. あなたのファイルを編集できる
   - D. 必ずローカルで動く
   > **答え：B。** 手順を選び直すか、どんな権限があるかを別に確認する必要があります。

4. **[応用・場面問題]** チャットの有料プランに加入した後、別ツールでAPIキーを求められました。何を確認しますか？ <!-- quiz: q04 revision: 1 -->
   - A. アイコンが同じか
   - B. モデル名が長いか
   - C. そのツールの認証方法とAPI利用がプランに含まれるか、別課金か
   - D. キーを公開して貼り付けられるか
   > **答え：C。** チャットの契約と開発者APIの残高は、自動的に同じ利用権にはなりません。

5. **[基礎・場面問題]** デスクトップの助手がクラウドモデルで文書を読んでいます。文書の内容はどこで処理され得ますか？ <!-- quiz: q05 revision: 1 -->
   - A. インストール先のパソコンだけ
   - B. モデルは入力を処理しないので、どこでも処理されない
   - C. プリンターだけ
   - D. アプリの送信内容に応じて、クラウドサービスでも処理される
   > **答え：D。** インストール場所と処理場所は別の問題です。

6. **[基礎・観察問題]** 製品が今回使用したモデルを公開していません。適切な説明は？ <!-- quiz: q06 revision: 1 -->
   - A. それらしいモデル名を作って答える
   - B. 製品と確認できる機能を示し、モデルは不明とする
   - C. モデルがないと決めつける
   - D. 最も高価なモデルだと決めつける
   > **答え：B。** 不明な部分があっても整理はできます。ブランド名だけではモデルの具体的なバージョンは分かりません。
