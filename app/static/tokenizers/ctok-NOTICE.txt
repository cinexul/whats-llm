Transformation: strip API probe witnesses; parse marker notation to internal codepoints; include upstream contraction spellings, unit pieces, and byte-prefix membership; deterministic JSON + gzip (mtime=0).
Browser implementation is a TypeScript count-only port of the pinned Python normalization and min-cost tiling algorithm. It does not expose or claim genuine Anthropic token IDs or segmentation. No API requests are made.
Content estimate subtracts the fixed six-token single-user-message frame; boundary and trailing-newline frame conventions remain. It is not an independently defined raw-text tokenizer or a guarantee of current Claude API counts.
